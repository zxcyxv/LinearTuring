# 해석 가능성의 경계선 — URM(softmax 트랜스포머)에서 안 되고 우리 구조에서 되는 것

> 상태 표기: [실측] 이미 실행·수치 있음 / [1일차 실측] CA·MNIST 에서 검증, 스도쿠 판 미실행 /
> [미실행] 구조적으로 보장되나 아직 안 돌림 — **논문 주장 전 실행 필수 목록이기도 함.**
> 정직 원칙: §3 에 "URM 도 되는 것"을 같이 적는다. 오늘 분석의 상당 부분은 그 부류다.

## 0. 차이의 구조적 근원 — 딱 두 개

1. **부호 어텐션**: a_tn ∈ [−1,1] (위상 정규화, 명제 1·2). softmax 는 비음+행합 1 이 정의라
   음수 간선이 원리적으로 없다. 우리의 간선 부호 = 흥분/억제 의미론이 어텐션 값 자체에 있음.
2. **조건부 선형성** (명제 21): 스칼라 장 {a^(m), d_t, ‖h‖(Φ 계수), (dt=1 판: 경계 SwiGLU 게이트)}
   를 기록하면 상태 갱신 전체가 h 에 **정확히 선형·아핀**. URM 은 장을 얼려도 층별 MLP 가
   h 에 비선형 — 어떤 동결로도 선형화되지 않는다 (activation patching 이 늘 근사인 이유).

## 1. URM 불가 / 우리 가능

| # | 능력 | URM 이 안 되는 수학적 이유 | 우리 상태 |
|---|---|---|---|
| A | **간선 부호 직독** — "이 헤드는 피어를 억제한다"를 어텐션 한 장에서 | softmax 비음성. 억제는 attn×OV×판독 합성으로만 간접 추론 (유도량·근사) | **[실측]** 억제 헤드 0·1: 피어질량 40~42%·음수 98% / head5 = 해결-게이트 수집 (미확정 피어 3.4배, 전 loop 일관) |
| B | **d_t = 부호 행합** — 칸별 "제약 압력" 스칼라 | softmax 행합 ≡ 1 (정보 없음) | 교리 도구 [1일차 실측 — CA c항 단독 0.766] |
| C | **정확 재생** — 기록 장 조건부 재생 오차 **문자 그대로 0** | MLP 비선형 → 동결 재생은 근사 | [1일차 실측: 3모델 오차 정확히 0] dt=1 판은 경계 게이트 기록 추가 필요 [미실행] |
| D | **정확 반사실** — 특정 간선·스텝·헤드를 기록 장에서 놕아웃 후 재생 → 무근사 인과 귀속 (X-Wing 급 기법 검증의 정공법) | patching = 근사 + 하류 재계산 오염 | **[미실행 — 1순위 청구서]** |
| E | **장 이식** — 샘플 i 의 장 × 샘플 j 의 상태 (개입 수준 인과, 명제 25) | 장-상태 분리 자체가 성립 안 함 | [1일차 실측: CA 0.85 vs 우연 0.52] 스도쿠 [미실행] |
| F | **항등 분해** logits = W·L_장[h₀] + c_장 — 운반자(수송 vs d_t·b) 귀속이 항등식 | 비선형이라 분해에 잔차 | [1일차 실측] 스도쿠 [미실행] |
| G | **간선별 에너지 귀속** — sheaf 수송에서 간선 에너지 부호 = sign(a) 보존 (명제 26·11) | softmax 확산은 항상 비음·소산 — "주입원 간선" 개념 자체가 없음 | [1일차 실측] |
| H | **게이지 회계** — γ 스케일 게이지·0차 동차 (진폭/방향 분리, 명제 2·4) | 대응 구조 없음 | [정리] |
| I | 균일상태 분산관계/닫힌 심볼 (흐름판; dt=1 판은 Floquet 승수로 변형) | 대응물 없음 | [1일차 실측, 흐름판 한정] |
| J | **진폭 발언권 채널** — ‖h_t‖ 가 자유도 (상대 진폭 = 수송 가중, 극분해) | RMSNorm 이 ‖h‖=√d 고정 — 채널 부재 | **[실측]** 확정 사건 정렬: 미확정 −5% 눌림 → 확정과 함께 상승 (3.51→3.71) |

## 2. 같은 발견이라도 "읽히는 깊이"가 다르다

head5 사건이 예시: URM 에서 같은 알고리즘이 돌아도 어텐션 그림에는 "피어를 본다"까지만 보인다.
"누른다/모은다"의 부호, "해결되면 끈다"의 게이트가 우리는 관찰량 자체에 있고, URM 은 회로 합성
추론이 필요하다. 관찰 대상도 우리는 가중치 공유라 "동일한 그래프 연산자의 256프레임 시계열"
하나지만, URM 은 층×헤드마다 다른 객체라 궤적 정의부터 조합적이다.

## 3. 정직 대비 — URM 도 되는 것 (오늘 분석의 상당 부분)

- 중간 판독(logit lens): 커밋 시점, 엔트로피 소거 곡선, 전파깊이 클래스 분해 — **완전 이식 가능**
  (URM 은 loop 판독이 학습돼 있어 오히려 자연스러움)
- 어텐션 질량 통계(피어 비중), 특정 간선의 시계열, "확정↔유입" 상관 — 대체로 이식 가능 (부호 제외)

## 4. 논문 전략 (이 문서의 용도)

같은 해석 배터리를 두 모델에 이중 적용한 3단 대비가 가장 강한 구도:
① 둘 다 보임 (커밋·엔트로피) → ② 우리만 직독 (부호·d_t·게이트) → ③ 우리만 가능 (C~F 무근사 인과).
**③ 없이는 차별점이 주장에 그친다 — D(정확 반사실)·E(장 이식) 스도쿠 실행이 선결 조건.**
