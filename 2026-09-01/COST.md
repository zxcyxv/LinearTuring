# 연산 병목 — 스도쿠에서 ARC 로 갈 때 무엇이 얼마나 비싸지는가

전부 실측. 단위는 **학습 1스텝 = 1 세그먼트(8블록) forward+backward**, 워밍업 후 반복 평균.

## 1. 비용이 사는 곳

`core/minimal.py` 의 `step()` 에서 `[B,H,T,T]` (토큰 쌍마다 값 하나) 모양을 만드는 지점:

```python
a     = self.attn_xy(xy, kc)                      # 전달 커널        (STDP 없어도 필요)
agree = einsum('bthc,bnhc->bhtn', vv, vv)         # ← STDP 전용
G     = self.attn_xy(xy, kcb) * agree             # ← STDP 전용 (커널 한 번 더 + 곱)
tgt   = softplus(gain_raw) * G                    # ← STDP 전용
w     = (1-eta)*w + eta*tgt                       # ← STDP 전용, 세그먼트를 넘어 **보존**
a_eff = (1-lam)*a + lam*w                         # ← STDP 전용
```

STDP 를 끄면 `a` 하나만 남는다. 켜면 블록마다 T×T 텐서가 예닐곱 개 더 생기고,
**8블록 기울기 창 전체에 걸쳐 역전파용으로 살아 있어야 한다.** `w` 는 활성값이 아니라 **상태**라
gradient checkpointing 으로 버릴 수도 없다.

T 는 81 → 900 이지만 **T² 는 6,561 → 810,000, 123배**다. 토큰당 파라미터 연산(경계 MLP 8.3M MAC/토큰)은
T 와 무관하므로, 작은 항이 큰 항이 된다.

## 2. STDP 도입 배수 (격자 크기별, eager)

| 격자 | T | T² | 배치 | STDP 끔 | STDP 켬 | 메모리 배수 |
|---|---:|---:|---:|---:|---:|---:|
| 9×9 | 81 | 6,561 | 32 | 1.049 GB | 1.510 GB | **1.44×** |
| 15×15 | 225 | 50,625 | 32 | 3.085 GB | 5.813 GB | 1.88× |
| 21×21 | 441 | 194,481 | 32 | 6.817 GB | 16.524 GB | 2.42× |
| 30×30 | 900 | 810,000 | 8 | 4.620 GB | 14.310 GB | **3.10×** |

## 3. 커널 융합 (torch.compile) 후

| 격자 | STDP | eager | compile | 메모리 | 시간 |
|---|---|---|---|---:|---:|
| 9×9 | 끔 | 1.057G / 59.3ms | 0.747G / 115.3ms | 0.71× | 1.95× (악화) |
| 9×9 | 켬 | 1.528G / 84.0ms | 1.133G / 97.9ms | 0.74× | 1.17× (악화) |
| 30×30 | 끔 | 4.620G / 201.0ms | 3.417G / 113.3ms | 0.74× | **0.56×** |
| 30×30 | 켬 | 14.342G / 474.3ms | **10.989G / 211.6ms** | 0.77× | **0.45×** |

**STDP 배수는 융합으로 안 줄어든다**: 30×30 에서 메모리 3.10× → 3.22×, 시간 2.36× → 1.87×.

이유: T² 비용의 본체는 "훑는 횟수"가 아니라 **backward 가 실제로 요구하는 저장 텐서**다.
블록당 저장 대상이 STDP 끔 = `a` 하나, 켬 = `a`, `agree`, `a^β`, `w`, `a_eff` 다섯 개.
커널 융합은 중간 텐서를 안 만들 뿐 backward 가 필요로 하는 값은 못 없앤다.

다만 **ARC 크기에서 절대 시간은 2.2배 빨라진다** (474 → 212ms). 작은 스도쿠에서는 오히려 느려진다
(커널 실행 오버헤드가 이득보다 큼) — 텐서가 커질수록 융합이 먹는다는 것 자체가 대역폭 병목의 서명이다.

## 4. 스도쿠 → ARC 이식 배수: URM 대 우리

배치 8, `torch.compile`, 1 세그먼트 forward+backward.
URM 은 `scripts/URM_sudoku.sh` 와 `URM_arcagi1.sh` 가 **아키텍처 설정이 동일**하므로 순수 T 효과다.

| 모델 | 파라미터 | T=81 | T=900 | 메모리 배수 | 시간 배수 |
|---|---:|---|---|---:|---:|
| URM (4층·H2·L6, h512) | 13.66M | 0.488G / 51.8ms | 4.387G / 197.3ms | **8.98×** | **3.81×** |
| 우리 STDP 끔 (h832) | 7.15M | 0.252G / 24.0ms | 3.414G / 112.4ms | 13.56× | 4.69× |
| **우리 STDP 켬** | 7.16M | 0.338G / 27.0ms | **10.773G / 210.9ms** | **31.89×** | **7.80×** |

**ARC 지점에서 절대 시간은 URM 과 사실상 같다 (210.9 vs 197.3ms = 1.07×). 메모리만 2.5배다.**

숨은 사실: 우리는 파라미터가 절반이고 세그먼트당 레이어 적용이 8회 대 48회로 1/6 인데 시간이 같다.
**적용 1회당 6배를 쓰고 있고, 그것을 깊이가 아니라 쌍 기억에 쓰고 있다.** 예산 배분을 바꾼 것이지 더 쓴 것이 아니다.

## 5. 왜 URM 은 완만한가 — 구조적 차이

`models/layers.py:133-138`: URM 의 어텐션은 `flash_attn_func`, 없으면 `scaled_dot_product_attention` 으로 간다.
(이 환경엔 flash_attn 미설치 → SDPA 폴백이지만 **SDPA 도 flash/mem-efficient 백엔드라 T×T 를 안 만든다.**)
따라서 URM 의 어텐션 활성 메모리는 **T 에 선형**이다.

우리는 `a` 를 명시적으로 만들어야 한다. `w` 가 토큰 쌍 위에 정의돼 있고, `agree` 가 쌍 행렬에 원소별로 곱해지고,
결합 `(1−λ)a + λw` 자체가 쌍 행렬이다. **T 에 제곱**이고 STDP 가 그것을 다섯 배로 늘린다.

**즉 지금 형태의 STDP 는 메모리 효율 어텐션과 원리적으로 양립하지 않는다. 최적화 격차가 아니라 구조적 격차다.**

### 인수분해로 피할 수 없다

- `a^β` 는 헤드당 랭크 ≤ 2p = 104, `agree` 는 랭크 ≤ C = 104.
- 두 저계수 행렬의 아다마르 곱은 카트리-라오 곱으로 **정확히** 인수분해되지만 랭크가 **104² = 10,816** 까지 오른다.
- T=900 에서 10,816 > 900 이므로 **인수분해가 명시적으로 만드는 것보다 비싸다.** EMA 는 랭크를 더 올린다.

**정확한 토큰-쌍 STDP 는 진짜로 O(T²) 상태를 요구한다.** 우회로는 셋뿐이다:
근사(저계수/스케치) · 시냅스 단위를 특징 쌍으로 변경 · 희소화(패딩 마스킹·국소 제한).

## 6. 특징 쌍으로 옮기는 경우의 정확한 손실

`Q_t = [qx_t; qy_t] ∈ R^{2p}`, `K_n = [kx_n; ky_n] ∈ R^{2p}` 로 두고 `w = (Q M Kᵀ) ⊙ decay`, `M ∈ R^{2p×2p}` 라 하면
`M` 은 `[B,H,2p,2p]` 로 **T 와 무관**하다. 표현 가능한 집합의 조건은 **정확히 `T ≤ 2p`**:

- **스도쿠**: T=81, 2p=104. `Q` 가 일반적으로 랭크 81 → `{Q M Kᵀ}` 가 R^{81×81} **전체**. `decay` 는 0이 없어 ⊙ 가 가역.
  자유도로 10,816 ≥ 6,561. → **어떤 토큰-쌍 `w` 든 정확히 표현된다. 손실 0 (증명).**
- **ARC**: T=900, 2p=104. 도달 집합은 10,816차원, 전체는 810,000차원 → **1.34%. 진짜 제약.**

따라서 **스도쿠는 "표현력"이 아니라 "갱신 규칙"만 시험하는 깨끗한 시험대**이고,
동시에 **스도쿠 결과로 ARC 를 검증할 수는 없다.**

정정: 앞서 "`a` 는 구조상 랭크 ≤ 104" 라 적은 것은 틀렸다. `a = (Q Kᵀ) ⊙ decay` 이고 **`decay` 는 정확히 꽉 찬 랭크**
(측정: 모든 헤드에서 81/81, T=900 에서 900/900). 랭크 ≤ 104 인 것은 내적부뿐이다.
다만 `decay` 의 *수치적* 랭크는 낮다 — 학습된 α=0.0202 헤드에서 σ > 1e-3·σmax 인 특이값이 81개 중 18개,
T=900 에서 900개 중 35개.

- **PR 72 는 대각이 만든 착시였다.** 대각이 에너지의 55.6% → 81.7% 를 먹고, 진짜 관계 성분(비대각)의

- 대각은 칸에 대해 사실상 상수다 — **변동계수 1.2%**, 헤드 간에는 15% 변동. 즉 사실상 **헤드당 스칼라**.

**함의**: O(T²) 로 저장하던 것의 대부분은 8개 스칼라면 충분한 항이었고, 진짜 관계 정보는 랭크 10 미만이다.
ARC 에서 필요한 랭크가 T 의 89% 라는 외삽은 이 분해로 무너진다. 게다가 스도쿠는 81칸이 전부 서로 다르고
전부 중요한 **최악의 경우**이며, ARC 는 대부분이 패딩·배경이라 주소 특징이 축퇴돼 랭크를 만들지 않는다.
