# 우리 아키텍처와 STDP·적응 결합의 대응 (2026-09-06)

작성: AI (Claude). 아키텍처 부분은 `kaggle/train_kaggle.py` (= 캐글 206k 런의 `lt_train.py`) 코드에서 직접 옮겼다.
문헌 식은 `papers/` 원문. "대응"과 "판정"은 해석이므로 코드·식과 구분해서 읽을 것.

이 문서는 **어디까지가 같은 식인가**만 다룬다. 무엇을 고칠지는 다루지 않는다.

---

## 1. 계산 순서

현행 설정: `num_layers=2`, `blocks_per_seg=8`, `block_order="post"`, `loops=16`,
`stdp=True, stdp_target="addr", stdp_window="psi", stdp_read="mul", stdp_diag="zero", dist_decay=False`.

### 1.1 세그먼트 하나

```
입력:  h (직전 세그먼트 carry, 첫 세그는 init_hidden),  w (결합 기억, 첫 세그는 0)

세그먼트 사전 계산 (h 무관, 레이어마다 1회):
    AB  = W_C(L)          wc_raw 를 QR → 행직교 [A;B]
    kc  = kernel(L, ψ)    decay·cos/sin (전달용 커널의 위상 오프셋 ψ)
    kcb = kernel(L, β)    쓰기 창용 커널  ← stdp_window="beta" 일 때만. "psi" 면 None

for rep in 1..8:                       # blocks_per_seg
  for L in [L0, L1]:                   # num_layers — 블록마다 레이어 교대
      h ← h + √d · Embed(x)                                  주입 (매 블록)
      ── step ─────────────────────────────────────────────
      ẑ  = normalize( W_C h )                                복소 주소, 헤드 단위 ‖ẑ‖=1
      a  = Σ_j r_tj r_nj cos(Δφ_tnj + θ_j·Δ_tn + ψ_j)        전달 커널
      v  = w_sh h                                            값 사영
      Γ_w = a_β (kcb 있으면) 또는 a                           쓰기 구동
      â  = Γ_w / rms_head(Γ_w),  대각 0                       무차원화
      w  ← (1−δ_L) w + δ_L · â                               결합 기억 갱신
      a_eff = a · exp( clamp( sign(a)·w , ±4 ) )              읽기
      f  = w_shᵀ Σ_n a_eff,tn v_n                            수송
      h  ← h + f
      ─────────────────────────────────────────────────────
      h ← h + W_d( ½ (W_g h) ⊙ (W_u h) )                     경계 (토큰 내 쌍선형)
      h ← Φ(h) = h / √(1 + γ‖h‖²)                            반경 사영

출력:  로짓 = W_cls h
       carry ← h.detach(),  w.detach()
```

세그먼트당 블록 적용 = 8 × 2 = **16회**. w 는 16회 갱신되고 레이어 0·1 이 번갈아 쓴다 (δ 가 서로 다름).

### 1.2 세그먼트 반복

세그먼트를 **16번** 반복한다 (`loops=16`). 세그먼트마다 로짓과 손실이 나온다 (URM 하네스, 세그먼트별 감독).
`h` 와 `w` 는 세그먼트를 넘어 이어지지만 **둘 다 경계에서 detach 된다** — 경사는 세그먼트 하나(블록 16회) 안만 본다.

추론 시 세그먼트 수를 16보다 크게 주는 것이 외삽(seg128 등)이다. 그 구간에는 손실이 없다.

## 2. 기준이 되는 문헌 식

```
φ̇_i  = ω_i + Σ_j K_ij · Γ(φ_i − φ_j)          (a) 위상, 빠름
K̇_ij = ε ( G(φ_i − φ_j) − K_ij )               (b) 시냅스, 느림
```

- `Γ` 는 전달의 위상 인자 = **PRC**(위상 반응 곡선). 뉴런 막의 성질.
- `G` 는 쓰기 구동 = **STDP 창을 주기로 접은 것** `G(Δφ) = Σ_k W(Δφ/ω + kT)`. 시냅스의 성질.
- 둘 다 Δφ 의 함수지만 **출처가 다른 두 함수**다. Aoki–Aoyagi: `Γ = sin(Δφ+α)`, `G = −sin(Δφ+β)`.
  `α−β` 가 규칙 종류를 정한다 (헤비안 / 인과 STDP / 반헤비안).

---

## 3. 수식적으로 동일한 것

| | 문헌 | 우리 |
|---|---|---|
| **창의 함수형** | `Γ = sin(Δφ+α)`, `G = −sin(Δφ+β)` | `a = Σ_j r r cos(Δφ_j + θ_j·Δ + ψ_j)`, `a_β` 는 ψ→β |
| **시냅스** | `K_ij` | `w_tn` |
| **쓰기 방정식** | `K̇ = ε(G − K)` | `w ← (1−δ)w + δ·â` |
| **시냅스 고정점** | `K* = G(Δφ*)` | `w* = ⟨â⟩` |
| 전달 | `K · Γ(Δφ)` | v2.1 `a·exp(sign(a)·w)`, 9/1 `(1−λ)a + λw` — **둘 다 곱이 아님** → §4.2 |

- **창**: `A·exp(−Δt/τ)` 의 지수 인자 자리에 Δφ 가 들어간다. 우리 지수는 허축이라 회전이고 STDP 는 실축이라 감쇠인데,
  둘을 잇는 것이 주기화다 — 실수 감쇠 창을 주기로 접으면 Δφ 의 주기함수가 되고 **그 1차 푸리에 모드가 `cos(Δφ+ψ)`** 다.
  ψ 가 그 모드의 위상 = LTP/LTD 비대칭. Aoki–Aoyagi 의 β 와 같은 자리.
- **쓰기 방정식**: `w ← (1−δ)w + δG` 는 `K̇ = ε(G−K)` 의 dt=1 전진오일러다. ε = δ. **문자 그대로 같은 식.**
- **블록 반복이 시간 적분이다**: 펼치면 `w^(K) = δ Σ_k (1−δ)^{K−k} â^(k)` — 새는 적분기. STDP 의
  `W(T) = ∫ e^{−(T−s)/τ_W} · 창(s) ds` 와 같은 객체.
- **전달**: 동일하지 않다. 곱 `K·Γ` 에 해당하는 읽기는 오늘 v3 의 `w·a` 가 처음이다 (§4.2).

## 4. 대응되지 않는 것 (하루 끝 기준으로 다시 씀)

### 4.1 G = Γ — 뉴런의 것을 시냅스에 쌓았다

문헌에서 두 함수는 **소속이 다르다**: Γ 는 받는 뉴런의 응답(PRC, 막의 성질), G 는 시냅스의 창(생화학). 스파이크 판에서 Γ 가 안 보이는 건 막 방정식 안에 숨어서고, 위상으로 줄이면 Δφ 의 함수로 드러난다. 읽기는 `K·Γ`, 쓰기는 `G` — 창은 쓰기에만 나온다.

`stdp_window="psi"` 는 읽기 커널 a(=Γ) 를 그대로 쓰기 구동에 넣는다. **응답 함수를 시냅스에 쌓는 것.** 결과는 식에서 바로 나온다:

- w 가 a 의 EMA 라 `w ≈ â`, `sign(w) = sign(a)`. 시냅스가 응답과 다른 말을 할 수 없다.
- 읽기 `a·exp(sign(a)·w)` 에서 지수가 `|a|/rms ≥ 0` → 이득 ≥ 1 항상. **시냅스가 상태 무관 날카로움 이득으로 퇴화**한다.
- 날카로움은 a 가 **현재값**일 때 제일 잘 드니 경사가 δ 를 **키운다** (v2.1 L1 0.08~0.22 실측). 느린 적분이 무용이 아니라 해롭다.
- `â = a/rms` 정규화와 `exp` 읽기는 이 퇴화의 부품이다 — G=Γ 에서 곱 `w·a` 가 부호 제곱이 되니 exp 로 우회하고, exp 가 인력만 키우니 `sign(a)·` 를 붙였다. 패치 두 겹.

원리: **쓰기 커널은 읽기 커널과 다른 함수여야 한다.** 그런데 "다르다"가 벡터에서 유일하지 않다 → 4.5.

### 4.2 읽기의 형태 — 곱이어야 하는데 9/1 은 덧셈, v2.1 은 exp

> **정정 (저녁, README §9–10)**: 이 절의 전제 "a ↔ Γ 이므로 읽기는 K·Γ = w·a 곱" 이 틀렸다. a 는 Γ 가 아니라 **순간 시냅스** K_fast = G(Δφ(t)) (K̇=ε(G−K) 의 ε→∞ 극한) 이고, w 는 같은 G 를 ε=δ 로 적분한 K_slow 다. 두 시냅스가 병렬이므로 전달은 (K_fast+K_slow)·Γ = (1−λ)a+λw, **덧셈**. 곱 w·a 는 시냅스×시냅스라 대응이 없고, 정상상태에서 sin 2χ 가 되어 주소 부호를 잃는다(ẑ_t→−ẑ_t 불변). 4.1 의 "G=Γ 퇴화" 도 같은 오인에서 나온 것 — G 와 K_fast 가 같은 함수인 것은 퇴화가 아니라 같은 규칙의 두 시정수. 문헌: 레퍼런스_덧셈결합.md.

STDP `I = Σ W·s`, 쿠라모토 `Σ K·Γ`. 둘 다 곱이다. 응답 Z(φ_i) 는 받는 쪽에만 걸리니 합 안으로 들어가고 한 주기 평균하면 `Γ(Δφ)` — 쿠라모토의 Γ 는 STDP 의 "받는 뉴런 응답 × 보내는 활동"을 평균낸 것. 그래서 완전한 읽기는 **시냅스 × 응답 × 활동**, 우리 말로 `w · a · v`.

| 읽기 | 꼴 | 빠진 것 |
|---|---|---|
| λ=1 (캐글) | `w·v` | 응답 — 라우팅이 낡음 |
| 기저 (STDP 없음) | `a·v` | 시냅스 |
| 9/1 add | `(1−λ)a·v + λw·v` | 응답 있는 항엔 시냅스가 없고 시냅스 있는 항엔 응답이 없음. **어느 원리에도 없는 근사** |
| v2.1 exp | `a·exp(sign(a)w)·v` | 4.1 의 패치. 부호 반전 불가 |
| 곱 | `w·a·v` | 없음 |

그리고 **같은 w 가 읽기에 따라 다른 것이 된다**: add 에서 w 는 a 와 반대 부호로 쌓여 결합을 **완충**했고(9/1 측정, 피어 a<0·w>0), 곱에서는 같은 w 가 결합을 **증폭**한다. 9/1 의 외삽 기제(느린 댐핑)는 덧셈 읽기의 현상이라 곱으로 바꾸면 보존된다는 보장이 없다.

### 4.3 적분 길이 — 결함이 아니라 4.1 의 결과

v2.1 의 δ (L0 .028 / L1 .082) 는 세그당 잔존 0.40, 기억 ≈ 1세그. 그런데 9/1 은 5헤드가 δ .002~.009 (14~57세그), 10k 재현은 균일 .05, 60k 에 갈라지고 120k 에 .013~.018. **시정수는 학습된다.** 짧은 것은 G=Γ 가 δ↑ 압력을 만든 결과다. 외삽 이득은 이 시정수에 용량-반응한다 (README §3).

경사가 세그먼트 하나(detach)만 보므로 δ↓ 압력은 "실려 들어온 w 가 유용할 때 보존이 이득"에서만 온다 — w 가 유용하려면 δ 가 작아야 하고, 순환이라 늦게 켜진다. G=Γ 면 w 가 신선한 복사본보다 유용해질 일이 없어 순환이 시작 안 된다.

### 4.4 ω 부재 — 탈출용이지 판별용이 아니다

`φ̇ = ω + …` 의 ω 가 없다. 결합을 끄면 위상이 정지한다. 이것이 빼앗는 것과 안 빼앗는 것을 갈라야 한다:

- **판별(어느 관계를 굳힐지)에는 필요 없다.** 문헌은 동질 진동자라 일관성 말고 증거가 없어 이탈로 일관성을 증거로 만들어야 했다. 우리는 격자 기하(`θ·Δ`)와 쓰기 커널 모양이 판별 재료다. 9/1 이 ω 없이 판별한다 (위반 쌍 95% 해소).
- **탈출(고정점 떠나기)에는 필요하다.** 순수 이완계는 고정점을 못 떠난다. 가짜 해가 고정점이면 규칙을 어떻게 고쳐도 안 나온다. 쿠라모토는 Δω, 다른 계열은 잡음/어닐링/백트래킹. 우리엔 없다.
- Δφ↔Δt 대응 자체는 주기 없이 성립한다 (부호 있는 반대칭 관계량, 원 위). Aoki–Aoyagi 도 위상 규칙을 유도 없이 놓는다. 다만 회전이 있어야 `sign(Δφ)` 에 "앞선다"는 시간 의미가 붙고, 이 과제는 숫자 치환 증강이라 그 방향이 원래 무의미하다 — 짝함수(헤비안) 끝이 맞고 홀함수(인과) 끝은 이 과제에 안 맞는다.

### 4.5 스칼라 조건이 벡터에서 세 갈래로 갈라진다

Seliger 에서 `G = cos` 는 동시에 (i) 정렬 인식 유사도, (ii) `−∫Γ` (Gushchin 경사계 조건), (iii) Γ 와 90° 다. 성분 416개인 우리는 셋이 다른 조건:

| | 조건 | 얻음 | 잃음 | 상태 |
|---|---|---|---|---|
| ① | β≡0, ψ≡π/2 | 유사도 + 경사계 | ψ 표현력 | 미검증 |
| ② | β≡0, ψ 자유 | 유사도 (정렬 인식, 대칭·PSD) | 경사계 | **9/1 학습 결과** |
| ③ | β=ψ+π/2, ψ 자유 | 경사계 (성분별 `G_j = −∫Γ_j`) | 정렬 인식 | **오늘 결정, v3** |

스칼라 이론은 이 셋을 구별 못 한다. 벡터판 정리는 없다. 9/1 절제: β 커널(②)로 쓰면 살고 ψ 커널(부호 무관)로 쓰면 죽는다 — "평균적으로 a_β ≈ −a" 는 `R(ψ)=0.22` 라 `a ≈ −0.22 a_β + 잡음`, 등가 아님.

### 4.6 결합 스케일과 자기결합

**스케일.** 쿠라모토 K 는 단위 크기(α~1). 우리 w 는 커널의 작은 크기를 물려받는다 — |a|, |a⊥| ~ ρ ≈ 0.08 (52성분 무작위 위상 합). 곱 읽기면 `|a_eff| ~ ρ² ≈ 0.006`, 기저의 1/12. 처방 = 쓰기 목표를 `|Z|` 로 나눠 **위상만** 기억 (`g·a⊥/(ρ+ε)`) → `a_eff ≈ (g/2)ρ sin 2χ`, Seliger `(α/2) sin 2Δφ` 에 진폭 게이트. ε 은 ρ≈0 쌍(주소 직교, 관계 없음)의 무작위 위상이 단위 크기로 쌓이는 것을 막는 게이트 — 쿠라모토엔 이 문제가 없다(모든 진동자가 확정 위상). ε=0.08 에서 3.5배 실측.

**자기결합.** 쿠라모토는 Γ 가 홀함수라 `K_ii·Γ(0) = 0` — 자기 힘이 자동으로 없다. 우리 `a_tt = Σ r² cos ψ` 는 ψ 퍼짐에서 0 이 아니다(9/1 −0.46, 자기반발). 9/1 은 `w_tt = +0.66` 브레이크를 학습해 상쇄했고 그걸 지우면 붕괴 — 계보에서 벗어난 쪽. ③ 곱 읽기는 `a_eff,tt = w_tt·a_tt` 인데 `a_tt` 와 `a⊥,tt` 는 같은 복소수 `Σ r² e^{iψ}` 의 실부·허부라 동시에 클 수 없고 어느 쪽이든 곱이 ≈0 → **Γ(0)=0 으로 복귀.** diag=keep 은 "안 지운다"이지 "있다"가 아니다.

### 4.7 표본을 가로지르는 누적이 w 에 없다

문헌의 K 는 환경과의 여러 조우를 가로질러 누적된다 — 우연은 흩어져 상쇄되고 일관된 관계만 남는 것이 STDP 의 인식론적 근거. 우리 w 는 한 퍼즐 안에서만 산다(`fresh`). 그 역할은 **지도학습된 가중치**가 한다 (1k×1000 증강을 가로질러 경사하강). K 의 자리가 둘로 갈라져 있다: 표본 간 = 가중치, 표본 내 = w. w 는 시냅스가 아니라 **eligibility trace** 자리이고, 3인자 규칙의 세 번째 인자(조절 신호)는 없다. 상관 기반 누적을 w 가 다시 하면 경사하강과 중복 — w 가 벌 수 있는 것은 그 퍼즐·그 순간에만 있는 양뿐.

## 5. 대응 안 되지만 기제에 걸리지 않는 것

| | 왜 상관없나 |
|---|---|
| 밀리는 변수가 φ 가 아니라 h | h 를 밀면 φ 가 움직여 되먹임 고리는 닫힌다 |
| 성분 j 합 | 쌍 하나의 복소 스코어 `Z = Σ_j q̂_j conj(k̂_j)` 를 계산하는 방법. 시간 적분은 w 가 따로 |
| 창 인자에 `θ_j·Δ_tn` | 쌍별 위상 오프셋의 일반화 |
| 노드당 위상 416개 | 진동자 묶음. splay 분류 등은 안 넘어오나 기제 무관 |

| 경계·Φ·주입 | 추가 항 |

## 6. 판정 보류

- **창의 폭 τ.** 코사인 하나는 가능한 가장 넓은 창. 성분 합은 같은 Δφ 의 고조파가 아니라 다른 Δφ 의 1차 모드라 못 좁힌다.
- **구동/회상 2국면.** 매 블록 재주입이라 K 가 혼자 패턴을 지탱하는 국면이 없다. 자율 동역학(재주입 없음 + 단서 클램프)이 그 국면을 만들지만 pre-norm 이 필요하고 노름·고정점 보장이 바뀐다 — 오늘은 안 함.
