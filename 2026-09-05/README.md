## 2. λ=1이 왜 틀렸나, v2는 무엇인가

- λ=1: `a_eff = w`, `w ← (1−δ)w + δ·a`. 스파이크 STDP의 전달 형태(시냅스 × 지금 pre 활동). 전달에 타이밍(위상 관계) 인자가 없다.
- 이 모델에서 제약 전파를 하는 것은 순간 위상 커널 `a_tn = e^{−α|Δ|}Σ_j r_tj r_nj cos(φ_tj−φ_nj+ψ_j)`다. 이걸 전달에서 빼면 w는 δ로 지연된 a 노릇밖에 못 한다(δ가 커진 것이 그 증거).
- 위상 진동자 STDP 문헌(§6)의 전달은 `K_ij · F(φ_i−φ_j)` = 시냅스 × 순간 위상 관계. 이전의 `(1−λ)a + λw`는 그 곱의 덧셈 근사였고, λ가 L0 0.64 / L1 0.29로 학습된 것은 두 항이 다 필요했다는 뜻.
- **v2 (`stdp_read="mul"`, `dist_decay=False`, `stdp_diag="zero"`)**: `a_eff = a · exp(clamp(w, ±4))` → v2.1에서 `exp(sign(a)·w)`로 수정(아래), `w ← (1−δ)w + δ·â`, `â = a / rms_head(a)`, 첫 블록 `w = 0`. Γ=a(agree 없음), G=1, λ 소멸. `"add"`로 두면 이전 경로 그대로.
  - w는 무차원 로그 이득. w=0이면 STDP 없는 모델과 정확히 같다(검증: 로짓 차 0.0, `analysis/v2_smoke.py`).
  - exp>0이라 a의 부호(반발)가 보존된다. `w·a` 곱은 부호가 제곱돼 반발이 사라지므로 쓰지 않았다.
- 검증 (`analysis/v2_smoke.py`, `v2_train_smoke.py`, `v2_resume_smoke.py`; 로그 `results/v2_train_smoke_mul.log`, `v2_resume_smoke.log`):
  - δ→0 ⇒ 비STDP 모델과 비트 동일; 역전파·δ 기울기 정상; NaN 없음.
  - 로컬 1 GPU 배치 64 학습 1,500스텝: lm_loss 1.65→0.90, train acc 0.39→0.66 (같은 조건 psi0_split 변형은 2,000스텝 0.57).
  - step_1500.pt에서 compile=True로 재개 → 1,600까지 학습·저장 정상. EMA 복원 확인.
- 같이 적용한 두 가지 (2026-09-05 저녁):
  - `dist_decay=False`: 거리 감쇠 e^{−α|Δ|₁} 제거(decay_h ≡ 1, alpha_raw 미사용). 근거: 안정성에 불필요·#155 원인 아님(§3), 위치는 θ·pos 회전이 맡음.
  - `stdp_diag="zero"`: 자기시냅스는 STDP에서 제외. mul 읽기에서 w_tt=0 → exp(0)=1이라 자기 결합은 a 그대로. 자기항 a_tt가 동료항의 ~10배라 â의 rms 정규화를 지배하던 것도 막는다.
  - 두 키 모두 재개 구조 키에 추가. 재검증: δ→0 비트 동일(로짓 차 0.0), 역전파 정상, 학습 스모크 `results/v2_train_smoke_mul_nodecay.log`.
- **v2.1 부호 대칭 이득 (2026-09-05 밤)**: `a_eff = a · exp(clamp(sign(a)·w, ±4))`.
  - 문제: `a·exp(w)`는 w가 â의 부호를 따르므로 일관된 반발(a<0, w<0)이 e^{−|w|}로 약해지고 인력만 커진다. 로컬 1,000스텝 ckpt, 실제 퍼즐 64개, 16세그 뒤 L1 측정(`analysis/v2_sign_asym_check.py`): 원래 a 인력 143.6k / 반발 147.6k → a·exp(w) 인력 429.4k (3.0×) / 반발 110.8k (0.75×). 긴 지평에서 인력 우세(과평활)로 기울고, 학습 지평에서는 벌충되지만 벌충량이 지평에 의존해 외삽에서 드러나는 결함.
  - 수정 후 같은 측정: 인력 153.6k→435.3k (2.8×), 반발 132.1k→347.3k (2.6×). 인력·반발 대칭. Seliger의 K·sin Δφ = (α/2) sin 2Δφ가 동위상·반위상을 똑같이 굳히는 것에 대응.
  - 1,000스텝 스모크(`results/v2_train_smoke_mul_signed.log`): 손실 1.85→1.02, train acc 0.36→0.71, eval acc 0.483. δ→0 비트 동일·역전파 정상 재확인.
- 캐글 실행 주의: `stdp_read`·`stdp_diag`·`dist_decay`가 재개 구조 키에 들어가므로 λ=1 런 output을 input으로 붙여도 "설정이 다르다" 경고 후 step 0부터 시작한다(의도된 동작). 이전 λ=1 파일은 `kaggle/train_kaggle_lam1_backup.py`.

### 3.1 위상이 내용을 담는가 (쿠라모토 대응의 전제) — 담는다

182k 체크포인트, seg16에서 푼 145/256 격자의 최종 상태. 주소 위상 φ_tj(위치 회전 θ·pos 제외), 진폭 가중 원형 평균 길이. 스크립트 `analysis/phase_content_probe.py`.

| 그룹 | 그룹 내 위상 집중도 | 라벨 섞기 기준 | 차이 | 차이>0.1인 성분의 에너지 비율 |
|---|---|---|---|---|
| L0 같은 숫자 | 0.99 | 0.50 | +0.49 | 97% |
| L0 같은 행/열/상자 | 0.41 | 0.50 | −0.09 | 0% |
| L1 같은 숫자 | 0.99 | 0.52 | +0.47 | 94% |
| L1 같은 행/열/상자 | 0.44 | 0.52 | −0.09 | 0% |

- 같은 숫자 칸은 거의 동일 위상(0.99), 위치는 위상에 없음(θ·pos 회전이 따로 맡음). 같은 단위 안의 칸들은 무작위보다 더 퍼져 있음 → 9숫자 = 9위상, Berner의 splay(R₂=0) 방향.
- 따라서 이 모델은 "위상이 곧 내용"인 진동자 망이고, 풀린 격자 = 같은 숫자 동위상 · 단위 splay인 위상잠금 상태. 쿠라모토 적응 결합과의 대응은 원리(두 시간척도, 위상 관계가 부호를 정하는 상호작용, 위상 관계로 완화되는 가소성, 여과, 구동)와 사실(위상=내용) 양쪽에서 성립.
- 문헌과의 남은 차이는 계열 안의 선택들: F=G(α−β=π인 한 점), 노드당 다중 성분 위상(진동자 묶음), h 전체를 미는 전달과 경계·Φ(추가 항), 레이어 2벌 교대(주기 2 변조), 시냅스 배율 exp(w)≥0(문헌 K는 음수 허용). 원리 수준에서 빠진 것은 없음.

## 3.3 대칭 경계·ψ=0 절제 (v2.1 계열, 로컬 배치 128)

- `boundary="sym"`: 현행 쌍선형 Δ = W_d(½g⊙u)를 삼선형 퍼텐셜 U = ½Σ g_i u_i c_i (c = W_dᵀh)의 경사 Δ = ½[W_d(g⊙u) + W_gᵀ(u⊙c) + W_uᵀ(g⊙c)]로. 새 파라미터 없음, 초기 Δ=0 동일. 야코비안 r: bilinear 0.995 → sym 0.000 (`boundary_sym_check.py`). 기본값은 bilinear.
- 야코비안 성분 (`jacobian_asym_v21.py`, v2.1+sym 1,800스텝 ckpt, #155 seg8): ψ 학습값에서 a 0.61/0.79, 수송(A 재계산) 0.74/0.93, 경계 0, Φ 0, 블록 전체 0.15. ψ=0 강제 시 a 0, 수송 A 얼림 0, 수송 A 재계산 0.12/0.13(빠진 주소 경사 항), 블록 전체 A 얼림 0.035/0.042(합성 순서 몫, 사용자 지시로 유지), 블록 전체 0.06.
- 학습 속도 스모크 (1,800스텝, train batch acc; 로그 `results/smoke_*_bs128.log`, `kaggle_v21_signed_0-1800.txt`):

|---|---|---|---|---|
| 400 | 0.490 | 0.528 | 0.522 | 0.481 |

  대칭 경계는 이전 규칙보다 빠르고(EqLT의 느림은 대칭화가 아니라 그때의 경계 구현 탓), v2.1 쌍선형보다는 느리다(실행 조건 차이 섞임). ψ=0은 확실히 느리다.

## 6. 문헌 (`papers/`)

- Seliger, Young, Tsimring 2002, PRE 65 041906 (`seliger_nlin0110044.{pdf,txt}`): φ̇_i = ω_i − (1/N)Σ K_ij sin(φ_i−φ_j), K̇_ij = ε(α cos(φ_i−φ_j) − K_ij). ε≪1일 때 쌍안정(기억), ε 크면 단일 상태. 군집 내 K=α cos Δφ → 배위상 쿠라모토. 외부 구동으로 위상 패턴을 강제하면 K에 굳고 구동 제거 후 유지. 우리 대응: K=w, ε=δ, α cos=Γ=a.
- Aoki–Aoyagi 2009 PRL 102 034101 / Berner–Schöll–Yanchuk 2018 (`berner_multicluster_1809.00573`): K̇ = −ε(sin(Δφ+β)+K). β가 규칙 종류(헤비안/인과 STDP/반헤비안)를 정하고, 위상잠금 해는 splay(R₂=0)·antipodal(0/π)·double antipodal뿐. 인과 STDP 영역은 혼돈.
- Gushchin–Mallada–Tang 2016 (`gushchin_plastic_1602.07012`): K 대칭·f 홀함수면 (φ,K) 합친 계가 경사계. V = −ΣK_ij F(Δφ) − Σq K + ½ΣK²/α, V̇ ≤ 0. 위상 동역학과 STDP 갱신이 같은 에너지의 경사. 인과(비대칭) 커널에는 성립하지 않음.
- 스파이크 STDP(Diehl–Cook 2015 MNIST)와의 차이: 스파이크 판 전달은 시냅스 × 지금 pre 활동(= λ=1), 위상 판 전달은 시냅스 × 지금 위상 관계(= v2).
