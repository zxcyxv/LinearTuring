## 0. 요약 (하루 끝에 정리)

> **정정 (저녁, README §9–10)**: §3–§5 와 §9 는 "a ↔ Γ, 읽기는 곱 w·a" 를 전제로 썼고 그 전제가 틀렸다. a = 순간 시냅스 K_fast = G(Δφ(t)), w = 같은 G 의 느린 적분 K_slow, 읽기 = (K_fast+K_slow)·Γ = (1−λ)a+λw (덧셈, 9/1 형). β≈0 은 "같은 G 를 두 시정수로" 이므로 자연스럽고 ⊥ 를 벌릴 이유가 없다. §9 의 |Z| 정규화는 곱 읽기의 ρ² 스케일 문제를 고치려던 것이라 덧셈에서는 불필요. 구현: kaggle/train_kaggle_v4.py. 문헌: 레퍼런스_덧셈결합.md.

아래 §1–9 는 시간순이고 §8 이 §3–5 를 정정한다. 최종 위치만 적으면:

1. **9/1 의 외삽 = 느린 변수 w 의 과도상태 완성.** 학습된 δ 가 학습 지평(16세그)보다 긴 시정수(14–57세그)를 만들고, 학습이 앞 1/3 만 본 궤적을 추론이 마저 간다. 추론 시점 δ 스윕으로 용량-반응 확정 (README §3). 상한 있음. 추론 중 학습이 아님.
2. **그 시정수가 유용해지는 조건은 쓰기 커널 ≠ 읽기 커널.** 9/1 은 β≡0(주소 공간의 표준 내적 = 정렬 검출)으로, 읽기 ψ 는 퍼진 전이 규칙으로 학습했다. 어제 캐글은 G=Γ 라 w 가 a 의 복사본이 되어 날카로움으로 퇴화.
3. **스칼라 쿠라모토의 조건 셋(유사도·−∫Γ·90°)은 벡터에서 갈라진다** (§8). 9/1 은 ②(유사도), 오늘 결정은 ③(성분별 −∫Γ). 어느 것이 옳은지 정하는 벡터 이론은 없다.
4. **읽기는 곱 `w·a`.** STDP·쿠라모토 둘 다 `시냅스 × 응답 × 활동`이고 9/1 의 덧셈은 어느 원리에도 없는 근사. 단, 곱은 9/1 의 댐핑 기제를 보존하지 않는다 (§8).
5. **쓰기 목표는 위상만** (§9): `g·a⊥/(|Z|+ε)`. ρ²→ρ. Seliger `(α/2) sin 2Δφ` 에 진폭 게이트.
6. 재현 검증 (README §2): 9/1 은 `gain_raw` 에 wd 가 걸린 채 돌았고 재현은 no-decay — seg16 곡선은 동일, gain↔λ 역할이 바뀜. 그 외 전부 AST 동일.

## 2. β → 0 이 뜻하는 것

```
a_β,tn = Σ_j r_tj r_nj cos(Δφ_j + θ_j·Δ_tn + β_j)  =  Re ⟨ ẑ_t , D_β R_Δ ẑ_n ⟩
         D_β = diag(e^{iβ_j}),   R_Δ = diag(e^{iθ_j·Δ})  (위치 회전)
```

β_j ≡ 0 이면 D_β = I 이고 **쓰기 커널은 주소 공간의 표준 에르미트 내적**이 된다.

- 대칭: a_β,tn = a_β,nt (R_{−Δ} = R_Δ^†).
- 두 주소가 기하를 감안해 일치하면 정확히 1, 아니면 작다.
- 정규화된 복소 벡터의 곱공간에서 "같은 상태인가"를 재는 표준 계량은 이것 하나다. β_j ≠ 0 은 그 계량을 성분별로 비트는 것이고, 비틀면 대칭이 깨지고 같은 주소에서도 1 이 안 나온다.

따라서 **β→0 은 과제와 무관한 고정점**이다. w 가 "어느 쌍이 같은 상태였나"를 담아야 유용하다면 그걸 재는 최적 함수는 유일하고 경사는 거기로 수렴한다. 10k 에서 β 가 초기 분포 그대로인 것은 시냅스의 용도를 아직 못 찾은 상태다.

### 2.1 agree 도 같은 논리

상태 h 는 두 투영을 갖는다 — 주소 `W_C h` 와 값 `w_sh h`. `agree = ⟨v̂_t, v̂_n⟩` 은 **값 공간의 표준 내적**이다. `a_β · agree` 는 두 부분공간에서의 동시 일치 = **전체 상태의 일치 검출**이다. agree 를 빼면 주소만 보게 되고, 값이 다른데 주소가 같은 쌍을 일치로 오판한다. 이론상 agree 는 옵션이 아니라 계량의 절반이다.

### 2.2 읽기 커널은 반대 역할

```
a_tn = Re ⟨ ẑ_t , D_ψ R_Δ ẑ_n ⟩ ,   ψ_j 원 위에 퍼짐 (R = 0.22)
```

계량이 아니라 **전이 규칙**이다. "n 이 상태 s 이면 t 를 T(s) 로 밀어라"의 T 를 D_ψ 가 담는다. 같은 주소여도 `Σ_j r_j² cos ψ_j ≈ 0` 이라 일치를 알아보지 못하는데, 그것이 맞다 — 읽기는 알아보는 게 아니라 미는 것이다.

### 2.3 해석틀

| | 역할 | 형태 | 과제 의존 |
|---|---|---|---|
| **쓰기 G** | 상태 일치 검출 | 상태공간의 표준 계량 (β≡0, agree) | **무관** — 유일 |
| **읽기 Γ** | 상태 전이 | 학습된 비틀림 (ψ 자유) | 의존 — 자유 |

학습은 앞의 것을 **발견**했고 뒤의 것을 **조형**했다.

### 2.4 "a_β ≈ −a" 에 대해

ψ 의 원형 평균이 π 라서 나온 말이다. 대수로는
```
a = Σ_j cos ψ_j · a_β,j − Σ_j sin ψ_j · b_j        (b_j = 직교 성분)
```
이고 ψ 가 전 성분 π 여야 a = −a_β 다. 실제 R(ψ) = 0.22 라 `a ≈ −0.22·a_β + 잡음`. 등가가 아니며 `−a·agree` 로 바꾼 절제가 0 인 것이 그 증거다. **본질은 부호가 아니라 β=0 이 만드는 계량 구조**다.

## 3. 쿠라모토로 옮기기

노드당 위상 하나인 S¹ 에서 표준 계량은 `cos Δφ = Re⟨e^{iφ_i}, e^{iφ_j}⟩` 다. **Seliger 의 G = α cos Δφ 가 정확히 "β = 0"** 이다 — 그가 고른 것이 아니라 원 위의 유일한 일치 계량이다.

읽기 `Γ = sin Δφ`. 그런데 `sin Δφ = −d(cos Δφ)/dΔφ`. **쿠라모토의 읽기는 쓰기 계량의 미분**이다. 90° 는 임의의 각이 아니라 퍼텐셜과 힘의 관계이고, Gushchin 의 `G = −∫Γ` 가 그 조건이며 그래서 경사계가 된다.

| | Seliger | 9/1 (학습 결과) |
|---|---|---|
| 쓰기 G | `cos Δφ` — S¹ 의 표준 계량 | β≡0 — 주소×값 공간의 표준 계량 |
| 읽기 Γ | `sin Δφ = −G′` | ψ 퍼짐 — 미분이 **아님**, 자유 전이 규칙 |
| 관계 | Γ = −G′ 강제 → 경사계 | 없음 → 경사계 아님 (명제 7) |

9/1 은 쿠라모토의 **쓰기 쪽 원리(계량)는 재발견**했고 **읽기 쪽 제약(Γ = −G′)은 따르지 않았다.** 성분별 미분이려면 ψ_j ≡ π/2 여야 하는데 ψ 는 퍼져 있다.

읽기를 미분으로 묶는 것은 (i) 동질 진동자에 맞는 선택이지 원리가 아니고 (ii) 이 과제에서 ψ=0 강제가 느렸다는 측정(2026-09-05 §3.3)이 있다.

**옮길 것: G 는 계량이어야 한다. 옮기지 않을 것: Γ 를 G′ 로 묶는 것.**

## 4. 전달식

쿠라모토는 `K·Γ` — 곱이다. 우리 말로 `w · a`.

문서(2026-09-05 §2)가 곱을 버린 이유는 "부호가 제곱돼 반발이 사라진다"였는데, 그것은 **G = Γ 였을 때**의 얘기다. G 가 계량(β=0)이고 Γ 가 비틀린 전이 규칙이면
```
sign(w) = sign(a_β) · sign(agree)   ⊥   sign(a)
```
라 곱이 제대로 부호를 갖는다. Seliger 의 `cos · sin` 이 부호를 갖는 것과 같은 이유다.

즉 **이론이 말하는 전달은 `w·a` 순수 곱**이다 — exp 도 rms 정규화도 λ 도 없이. v2.1 의 `exp(sign(a)·w)` 와 `â = a/rms` 는 G=Γ 의 부호 제곱을 우회하려던 패치였고, G 가 계량이면 패치할 것이 없다.

`(1−λ)a + λw` 덧셈은 문서 스스로 "곱의 덧셈 근사"라고 적은 것이다. 9/1 이 그걸 쓴 것은 그때 구현이 그래서지 이론이 그래서가 아니다.

첫 블록: `w = None → w = tgt` 이므로 전달은 `gain · a_β · agree · a` 에서 시작한다. 쿠라모토에서 K 가 처음부터 0 이 아닌 것과 같다.

## 5. 이론이 말하는 설정

```
쓰기:  G = a_β · agree,   β ≡ 0  (또는 학습 → 0 으로 감)       ← 9/1 이 학습으로 증명
읽기:  a,  ψ 학습 (자유)                                       ← 9/1 이 학습으로 증명
w:     w ← (1−δ) w + δ·gain·G,   δ 학습                        ← 9/1: 느린 헤드 δ≈0.003 (README §4)
전달:  Σ_n (w_tn · a_tn) v_n     순수 곱. exp·rms·λ 없음         ← **미검증. 이론의 예측**
```

시정수는 설정하는 것이 아니라 **학습이 정한다.** 그 조건이 위 셋(계량 쓰기·자유 읽기·같은 스케일)이다 (README §6.2).

| 항목 | 9/1 | v2.1 | 이론 |
|---|---|---|---|
| `stdp_target` | faithful | addr | **faithful** |
| `stdp_window` | beta | psi | **beta** (β≡0 고정 가능) |
| `stdp_read` | add | mul(exp) | **mul, 순수 곱** — 새 값 필요 |
| `stdp_diag` | keep | zero | keep (9/1 에서 zero 는 붕괴) |
| rms 정규화 | 없음 | 있음 | **없음** |
| λ | 학습 | 없음 | **없음** (곱에는 λ 자리가 없다) |

이 중 **전달식만 학습된 적이 없다.** 곱으로 가면 이론의 예측을 검정하는 실험이고, 덧셈으로 가면 9/1 의 복원이다.

## 8. 정정 (같은 날 저녁) — 스칼라 이론은 벡터에서 세 갈래로 갈라진다

§3–5 는 "G 는 계량, Γ 는 자유, 전달은 곱" 을 한 묶음으로 적었는데, 그건 **스칼라 쿠라모토의 직관을 벡터에 그대로 옮긴 것**이고 그 옮김이 유일하지 않다.

스칼라 (Seliger) 에서는 `G = cos` 가 동시에 (i) 정렬 인식 유사도, (ii) `−∫Γ` (경사계 조건), (iii) Γ 와 90° 다. 한 문장이다.
성분이 416 개인 우리 모델에서는 이 셋이 **서로 다른 조건**이 된다:

| | 조건 | 얻는 것 | 잃는 것 | 상태 |
|---|---|---|---|---|
| ① | β≡0, ψ≡π/2 | 유사도 + 경사계 (스칼라 그대로 들어올림) | ψ 의 표현력 | 미검증 |
| ② | β≡0, ψ 자유 | 유사도 | 경사계 | **9/1 이 학습으로 고른 것** |
| ③ | β = ψ+π/2, ψ 자유 | 경사계 (성분별 `G_j = −∫Γ_j`) | 정렬 인식 (같은 주소에서 `−Σ r_j² sin ψ_j ≈ 0`) | 미검증 |

스칼라 이론은 이 셋을 구별하지 못한다. §5 의 "이론이 말하는 설정" 은 ② 의 쓰기에 곱 읽기를 붙인 것이고, 그 조합에 대한 정리는 없다.

**두 번째 정정 — 읽기와 기제.** §6.3 의 "w = 반헤비안 댐퍼 / unlearning" 판정은 **덧셈 읽기 위에서** 나온 것이다. 같은 w 를 곱으로 읽으면 (`a_eff = w·a`) 유사한 쌍에서 w>0 이 a 를 **증폭**한다 — v2.1 의 exp 와 같은 방향. 9/1 의 외삽 기제(느린 댐핑)는 덧셈 읽기의 현상이고, 곱 읽기가 그 기제를 보존한다는 보장이 없다. 곱에서 외삽을 줄 수 있는 것은 다른 기제(비유사 쌍 w<0 → 결합 반전 = 쿠라모토식 새 평형)이며 검증된 적 없다.

**다음 단계 (사용자 결정): ③ + 곱 읽기.** 성분별 90° 로 Gushchin 조건을 그대로 들어올린 것. β 파라미터 없음, ψ 자유. `kaggle/train_kaggle.py` 에 `stdp_window="perp"`, `stdp_read="prod"` 로 구현 (2026-09-06). 스모크: 순전파·역전파 정상, `corr(a, a_perp) ≈ 0`, β.grad None.
③ 에서 자기결합: `a_perp,tt = −Σ r_j² sin ψ_j ≈ 0` 이라 `w_tt ≈ 0`, `a_eff,tt = w_tt·a_tt ≈ 0` — 9/1 의 "대각 브레이크"(w_tt +0.66) 가 구조적으로 사라진다. 학습이 이걸 어떻게 처리하는지가 첫 관찰점.

## 9. 다음 후보 — 쓰기 목표를 |Z| 로 정규화 (위상만 기억)

복소 스코어 `Z = ⟨ẑ_t, D_ψ R_Δ ẑ_n⟩`, `a = Re Z`, `a⊥ = a(ψ+π/2) = −Im Z`, `ρ = |Z|`, `χ = arg Z`. ③ 의 `a_eff = w·a ≈ (ρ²/2) sin 2χ` 는 ρ² 이라 초기 결합이 기저의 1/12 (ρ≈0.08). 쓰기 목표를

```
tgt = gain · a⊥ / (ρ + ε)          (= −g · Im Z / |Z|)
```

로 두면 w 는 **위상 관계만** 기억하고 (sin χ, 단위 크기), 코히런스 ρ 는 읽기에서만 들어와 `a_eff ≈ −(g/2)·ρ·sin 2χ` — Seliger 의 `K·sin Δφ = (α/2) sin 2Δφ` 에 진폭 게이트가 붙은 정확형. ρ² → ρ 로 초기 결합 스케일이 구조적으로 회복된다.

- ε 필수: ρ≈0 인 쌍(주소 직교, 관계 없음)의 무작위 χ 가 단위 크기로 쌓이는 것을 막는다. ε ~ ρ 전형값(0.08).
