## §0. 출처와 한계 — 먼저 읽을 것

```
됨      전사 검증 1 · STDP 전개 2 + 정본 1 · 순전파 전개 2 + 정본 1 · 대응 관점 6
안 됨   반박 16 중 14 (입력 누락) · 판정 8 · 종합 · 완전성 비판        ← 지출 한도 + 스크립트 버그
```

- 스크립트의 문자열 보간 버그로 **단계 간 결과가 전달되지 않았다.** 따라서
  - STDP 정본(§3)은 표준 모형만 보고 독립 유도한 것 — 명세와 무관하므로 온전하다. 다만 연속/이산 두 전개와의 대조는 못 했다.
  - 순전파 전개와 대응 관점 6개(§4)는 **정정 전 명세**(블록 순서·Φ 위치·주입 계수가 틀린 것)를 보고 작업했다. 스텝 S1~S11 의 대수는 정정 전후가 같으므로 그 부분의 대응은 유효하나, 블록 순서·Φ·주입에 관한 행은 그 한계를 달고 읽어야 한다.
  - 관점 6개는 서로를 보지 못했다. §4 의 "합의"는 **독립 6회의 일치**이지 검산된 결론이 아니다.
- 순전파 전개(2+정본)는 정정 전 명세 기반이라 본문에서 뺐다. 정정본(§2)이 그 자리를 대신한다.
- 수치 측정·과거 문서 인용은 워크플로 전 에이전트에 금지했다. 유일한 예외는 §2 의 전사 검증(모델 정의 파일 읽기, 실행 없음).

```
[아키텍처 순전파 명세 — 정정본]
기호: 토큰 t,n ∈ {1..T} (T=81, 2D 격자 위치 pos_t = (t div 9, t mod 9) ∈ Z²). 블록 지표 k. 헤드 m 은 생략 (헤드마다 독립, 파라미터는 헤드별). 상태 h_t(k) ∈ R^d. 주소 성분 j ∈ {1..p} (복소). 값 채널 c ∈ {1..C}. C = d/H, p = C/2 (addr_dim 분할 없음 — 주소·값 경로 모두 전체 h 에 작용).
모든 블록은 같은 가중치를 쓴다 (num_layers=1 일 때; 일반적으로 블록 k 는 레이어 k mod num_layers 의 가중치를 쓴다 → 기본 구성에서 사상은 자율적).

에피소드 초기 상태: h_t(0) = h_init (d 차원 고정 벡터, 모든 토큰 동일, 학습 안 함). w, z 는 첫 블록에서 아래 규칙으로 생성.

블록 k 의 순서 (block_order = "post", 코드가 강제):
(I) 주입:               h_t ← h_t + √d · E(x_t)      (√d 고정 상수, 학습 안 함; E 임베딩, 초기 std 1/√d; x_t = 위치 t 의 입력 토큰 — 단서·빈칸 모두)
(S) 스텝 (Φ 없음; 아래 u, v 는 주입된 h 에서 계산):
 S1  u_t = W_C h_t ∈ C^p                                  W_C = A + iB, [A;B] ∈ R^{2p×d} 는 헤드별 행직교 행렬 (QR 재파라미터화) ⇒ ‖u_t‖ ≤ ‖h_t‖
 S2  û_t = u_t / (‖u_t‖ + ε)                              ‖·‖ 는 p 개 복소 성분 전체의 L2, ε = 1e−4. 성분별 û_{t,j} = r̂_{t,j} e^{i φ̂_{t,j}}, Σ_j r̂_{t,j}² = 1
 S3  z_t(k) = μ ⊙ z_t(k−1) + √(1−ρ²) ⊙ u_t(k),   μ_j = ρ_j e^{i ω_j},  ρ_j = sigmoid(·) ∈ (0,1), ω_j ∈ R  (성분별·헤드별 파라미터; 정규화 전 u 사용)
     에피소드 첫 블록: z_t = √(1−ρ²) ⊙ u_t  (z(k−1)=0)
 S4  ẑ_t = z_t / (‖z_t‖ + ε)                              성분별 ẑ_{t,j} = ř_{t,j} e^{i φ̌_{t,j}}
 S5  읽기 커널:  a_tn = D(Δ_tn) · Σ_j Re[ conj(q_{t,j}) k_{n,j} ],
                 q_{t,j} = û_{t,j} e^{i(θ_j·pos_t + ψ_j/2)},  k_{n,j} = û_{n,j} e^{i(θ_j·pos_n − ψ_j/2)}
     ⇒ a_tn = D(Δ_tn) · Σ_j r̂_{t,j} r̂_{n,j} cos( φ̂_{t,j} − φ̂_{n,j} + θ_j·Δ_tn + ψ_j ),   Δ_tn = pos_t − pos_n  (t = 읽는 쪽)

 S6  쓰기 창:   a^β_tn = D(Δ_tn) · Σ_j ř_{t,j} ř_{n,j} cos( φ̌_{t,j} − φ̌_{n,j} + θ_j·Δ_tn + β_j )     (ψ 대신 β, û 대신 ẑ; D 는 S5 와 같은 α)
 S7  v_t = W_sh h_t ∈ R^C  (헤드별 W_sh ∈ R^{C×d}) ;  v̂_t = v_t/(‖v_t‖+ε) ;  agree_tn = ⟨v̂_t, v̂_n⟩ ∈ [−1,1]
 S8  G_tn = a^β_tn · agree_tn ;   tgt_tn = softplus(g) · G_tn   (g 헤드별)

 S10 a^eff_tn = (1−λ) a_tn + λ w_tn ;   λ = sigmoid(·) ∈ (0,1) 헤드별

(B) 경계 (토큰 내부):   h_t ← h_t + W_d [ ½ (W_g h_t) ⊙ (W_u h_t) ]      (W_g, W_u, W_d 편향 없음; W_d 영초기화; 활성화 없음; 헤드 무관)
(Φ) 정규화 (블록 끝):   h_t ← Φ(h_t),   Φ(h) = h / √(1 + γ ‖h‖²),  γ = 1/d 고정 (학습 안 함; 포화 반경 √d)

블록 간 이월: h, w, z.  세그먼트 = 8 블록. 세그먼트 끝에서 h, w, z 를 detach (값은 이월, 기울기 절단). 로짓 = W_cls h_t + b_cls (세그먼트 끝마다 감독; Φ 를 지난 h). 학습 시 16 세그먼트 뒤 정지, 추론 시 세그먼트 수는 하네스 소관 (미확인).
'에피소드 첫 블록' = 새 퍼즐이 시작되는 세그먼트의 첫 블록 (fresh 플래그); 같은 에피소드 안에서는 세그먼트를 넘어도 w, z 가 이월된다.
```

## §3. STDP 두 층위 — 정본 (표준 모형에서 독립 유도)

기호: 시냅스 i→j, 시차 s = t_post − t_pre, 뱅크 채널 ℓ, [안] = 창 컨볼루션, [밖] = 시간 누적. 연속과 이산을 병기.

```
기호 약속. 시냅스 i→j (i 전, j 후). 연속 t ∈ [0,T]; 이산 k ∈ {1..K}, 단계 Δ, t = kΔ. 시간차 s = t_post − t_pre (연속), m = k_post − k_pre (이산). 뱅크 채널 첨자는 ℓ (원문 S4 의 'Σ_j Z_j* Ŵ_j Z_i' 의 j 는 뉴런 j 가 아니라 채널 첨자이므로 ℓ 로 바꿔 쓴다). 푸리에 관례 Ŵ(ω) = ∫W(s)e^{−iωs}ds, Ŝ(ω) = ∫S(t)e^{−iωt}dt. [안] = 안쪽 적분(창 컨볼루션), [밖] = 바깥 적분(시간 누적).

════ (가) 수식 전문 (연속 ‖ 이산) ════

A. 스파이크 열 (S1)
연속: S_i(t) = Σ_f δ(t − t_i^f), S_j(t) = Σ_g δ(t − t_j^g)   (차원 1/시간)
이산: s_i[k], s_j[k] ∈ {0,1}   (무차원; S(t)dt ↔ s[k])

B. 창 (S2)
연속: W(s) = A₊ e^{−s/τ₊} (s>0),  −A₋ e^{+s/τ₋} (s<0),  W(0) := 0 (관례)
  인과 분해: W(s) = W₊(s) − W₋(−s),  W₊(s) = A₊e^{−s/τ₊}Θ(s),  W₋(s) = A₋e^{−s/τ₋}Θ(s)
  짝/홀: W_e(s) = [W(s)+W(−s)]/2,  W_o(s) = [W(s)−W(−s)]/2
  Ŵ(ω) = A₊τ₊/(1 + iωτ₊) − A₋τ₋/(1 − iωτ₋) = Ŵ_e(ω) + Ŵ_o(ω)   (Ŵ_e 실수, Ŵ_o 순허수)
  Re Ŵ(ω) = A₊τ₊/(1+ω²τ₊²) − A₋τ₋/(1+ω²τ₋²)
  Im Ŵ(ω) = −ω[ A₊τ₊²/(1+ω²τ₊²) + A₋τ₋²/(1+ω²τ₋²) ]   (ω>0 에서 항상 음)
  Ŵ(ω) = |Ŵ(ω)| e^{iψ(ω)},  ψ(ω) = atan2(Im Ŵ, Re Ŵ),  ψ(−ω) = −ψ(ω)
  Ŵ(0) = A₊τ₊ − A₋τ₋   (창의 적분 = DC)
  균형·대칭 특수경우 (τ₊=τ₋=τ, A₊=A₋=A): Ŵ(ω) = −2iAτ²ω/(1+ω²τ²),  |Ŵ| = 2Aτ²|ω|/(1+ω²τ²) (최대 Aτ, ω=1/τ),  ψ = −(π/2)·sgn ω,  Ŵ(0)=0
이산: W[m] = A₊ρ₊^m (m≥1),  −A₋ρ₋^{−m} (m≤−1),  W[0] = 0 또는 A₊−A₋ (갱신 순서 관례),  ρ± = e^{−Δ/τ±}
  Ŵ(Ω) = Σ_m W[m]e^{−iΩm} = A₊ρ₊e^{−iΩ}/(1 − ρ₊e^{−iΩ}) − A₋ρ₋e^{iΩ}/(1 − ρ₋e^{iΩ}),  Ω ∈ [−π,π)   (W[0]=0)
  Ŵ(0) = A₊ρ₊/(1−ρ₊) − A₋ρ₋/(1−ρ₋)

C. 쌍 합 (정의; [안]+[밖] 이 합쳐진 원형)
연속: Δw_ij = Σ_{f,g} W(t_j^g − t_i^f) = ∫_0^T dt [밖] ∫_0^T dt′ [안] S_j(t) W(t−t′) S_i(t′)
이산: Δw_ij = Σ_{k=1}^K [밖] Σ_{k′=1}^K [안] s_j[k] W[k−k′] s_i[k′]
전역 푸리에 형 (P3 의 [안] 을 주파수로, 끝점 T 에서 한 번만 읽는 형):
연속: Δw_ij = ∫_{−∞}^{∞} dω/(2π) Ŵ(ω) conj(Ŝ_j(ω)) Ŝ_i(ω) = ∫_0^∞ (dω/π) |Ŵ(ω)| |Ŝ_i(ω)| |Ŝ_j(ω)| cos( φ_i(ω) − φ_j(ω) + ψ(ω) ),  Ŝ = |Ŝ|e^{iφ}
이산: Δw_ij = ∫_{−π}^{π} dΩ/(2π) Ŵ(Ω) conj(ŝ_j(Ω)) ŝ_i(Ω),  ŝ(Ω) = Σ_k s[k]e^{−iΩk}
  고립 쌍 하나(전 t_i, 후 t_j = t_i + s): conj(Ŝ_j)Ŝ_i = e^{iωs}, 즉 φ_i(ω) − φ_j(ω) = ω·s. 이산: = e^{iΩm}, φ_i − φ_j = Ω·m.
  (검산: 균형·대칭 창에서 ∫_0^∞(dω/π)·2Aτ²ω sin(ωs)/(1+ω²τ²) = A e^{−|s|/τ}·sgn s = W(s). 일치.)

D. 안쪽 적분 — 갈래 1 (인과 흔적, S3)
연속: x_i(t) = (W₊*S_i)(t) = A₊Σ_f e^{−(t−t_i^f)/τ₊}Θ(t−t_i^f),  dx_i/dt = −x_i/τ₊ + A₊S_i(t)
      y_j(t) = (W₋*S_j)(t),  dy_j/dt = −y_j/τ₋ + A₋S_j(t)
이산: x_i[k] = ρ₊x_i[k−1] + A₊s_i[k],  y_j[k] = ρ₋y_j[k−1] + A₋s_j[k]
뱅크로 본 갈래 1: x_i(t) = ∫dω/(2π) Ŵ₊(ω) Z̃_i(ω;t)|_{τ_z=∞}  (무감쇠 뱅크 + 채널가중 Ŵ₊) = A₊·Z̃_i(0;t)|_{τ_z=τ₊} (감쇠 뱅크의 ω=0 채널 1개). 두 배치가 동치.

D′. 안쪽 적분 — 주파수 뱅크 (S3, 인과·온라인)
연속: Z̃_i(ω;t) = ∫_{−∞}^t e^{−(t−t′)/τ_z} e^{iω(t−t′)} S_i(t′) dt′,  dZ̃_i/dt = (−1/τ_z + iω) Z̃_i + S_i(t),  Z̃ = R e^{iφ}
이산: Z̃_i(ω;k) = μ_ω Z̃_i(ω;k−1) + s_i[k],  μ_ω = ρ_z e^{iΩ},  ρ_z = e^{−Δ/τ_z},  Ω = ωΔ
  (정규화 변형: Z̃_i(ω;k) = μ_ω Z̃_i(ω;k−1) + √(1−ρ_z²) s_i[k]. 이 전인자는 표준 STDP 에 없음.)
  뱅크 구적: ∫dω/(2π) f(ω) → Σ_ℓ c_ℓ f(ω_ℓ). 양의 ω_ℓ 만 쓰면 실수화는 Re[·] (c_ℓ 에 2 를 흡수).
  독립 포아송 입력의 채널 평균 (율 성분의 누출): E Z̃_i(ω;t) = ν_i /(1/τ_z − iω) (연속),  E Z̃_i(ω;k) = ν_i/(1 − μ_ω) (이산, 정상). 위상 arg = atan(ωτ_z) 는 뉴런에 무관하게 공통.

E. 구동 (S4)
갈래 1 (한쪽 순간·한쪽 필터):
연속: D₁(t) = S_j(t) x_i(t) − S_i(t) y_j(t)   (스파이크 시각에만 비영)
이산: D₁[k] = s_j[k]x_i[k] − s_i[k]y_j[k]  ⇒ 동시 빈 W[0] = A₊ − A₋;  W[0]=0 을 원하면 s_j[k]·ρ₊x_i[k−1] − s_i[k]·ρ₋y_j[k−1]
갈래 2 (양쪽 필터, 뱅크):
연속: Q_ij(t) = ∫dω/(2π) Ŵ(ω) conj(Z̃_j(ω;t)) Z̃_i(ω;t) = ∫_0^∞(dω/π) |Ŵ(ω)| R_j R_i cos( φ_i − φ_j + ψ(ω) )
이산: Q_ij[k] = Σ_ℓ c_ℓ Ŵ(ω_ℓ) conj(Z̃_j(ω_ℓ;k)) Z̃_i(ω_ℓ;k) = Σ_ℓ c_ℓ |Ŵ_ℓ| R_j R_i cos( φ_i − φ_j + ψ_ℓ ),  ψ_ℓ = ψ(ω_ℓ)
갈래 2 를 쌍 합으로 풀면 (유도: 2t − t′ − t″ = 2(t − max) + |t′ − t″|):
연속: Q_ij(t) = Σ_{f,g: t_i^f,t_j^g ≤ t} e^{−2(t − max(t_i^f,t_j^g))/τ_z} · W̃(s_fg),  W̃(s) = e^{−|s|/τ_z} W(s)
이산: Q_ij[k] = Σ_{쌍 ≤ k} ρ_z^{2(k − max)} · W̃[m],  W̃[m] = ρ_z^{|m|} W[m]
갈래 1 ↔ 갈래 2 정확 관계:
연속: dQ/dt = −(2/τ_z) Q + [ S_j x̃_i − S_i ỹ_j ],  x̃, ỹ 는 τ̃± = (1/τ± + 1/τ_z)^{−1} 의 흔적 (즉 창 W̃ 의 갈래 1 구동)
이산: Q[k] = ρ_z² Q[k−1] + [ s_j[k]·Σ_ℓ c_ℓŴ_ℓ μ_ℓ Z̃_i(ω_ℓ;k−1) + s_i[k]·Σ_ℓ c_ℓŴ_ℓ conj(μ_ℓ Z̃_j(ω_ℓ;k−1)) ] + s_i[k]s_j[k]·W_bank[0]
  ⇒ Q 는 '누설 2/τ_z (이산 ρ_z²) 를 가진 가중치' 즉 S5 형 객체이지, 순간 구동(S4 형) 이 아니다.

F. 바깥 적분 (S5)
연속(표준, 누설 없음): w_ij(T) = w_ij(0) + ∫_0^T D₁(t) dt = w_ij(0) + Σ_{f,g} W(s_fg)
이산: w[K] = w[0] + Σ_{k=1}^K D₁[k]
누설 변형(표준 밖): dw/dt = −(w − w₀)/τ_w + D₁ ;  EMA: w[k] = (1−η)w[k−1] + η g[k],  τ_w = Δ/η,  H(Ω) = η/(1 − (1−η)e^{−iΩ}),  |H(0)| = 1
갈래 2 위에 바깥 적분을 걸면:
연속: ∫_0^T Q(t)dt = Σ_{f,g} (τ_z/2)(1 − e^{−2(T−max)/τ_z}) W̃(s_fg) → (τ_z/2)·Σ W̃(s_fg)
이산: Σ_{k=1}^K Q[k] = Σ_쌍 (1 − ρ_z^{2(K−max+1)})/(1−ρ_z²) · W̃[m] → [1/(1−ρ_z²)]·Σ W̃[m]

G. 전달 (S6)
연속: I_j(t) = Σ_i w_ij(t)(κ*S_i)(t) + I_ext,j(t),  κ=δ 최단순, 일반 κ(u) = (1/τ_s)e^{−u/τ_s}Θ(u)
이산: I_j[k] = Σ_i w_ij[k−1](κ*s_i)[k] + I_ext,j[k]  (같은 단계의 학습 갱신 이전 값 사용)

H. 뉴런 (S7)
연속: τ_m dV_j/dt = −V_j + I_j ;  V_j ≥ θ ⇒ 스파이크, V_j ← V_r
이산: V_j[k] = e^{−Δ/τ_m}V_j[k−1] + (1 − e^{−Δ/τ_m}) I_j[k] ;  s_j[k] = Θ(V_j[k] − θ) ;  s_j[k]=1 ⇒ V_j[k] ← V_r
율 환원(표준 밖): ν_j = g(I_j), LIF: g(I) = [τ_ref + τ_m ln((I−V_r)/(I−θ))]^{−1} (I>θ).
  쌍 규칙 기대값: d⟨w⟩/dt = Ŵ(0) ν_iν_j + ∫ W(s) c_ij(s) ds,  c_ij(s) = ⟨S_j(t)S_i(t−s)⟩ − ν_iν_j
  독립 포아송 분산: Var[Δw] = ν_iν_j T ∫W² ds + ν_iν_j(ν_i+ν_j) T Ŵ(0)²,  ∫W² = (A₊²τ₊ + A₋²τ₋)/2

I. 시간축 (S8)
t = kΔ ;  ∫dt ↔ Δ·Σ_k ;  δ(t) ↔ s[k]/Δ ;  ρ = e^{−Δ/τ}, Ω = ωΔ ;  τ/Δ = −1/ln ρ. 이산 모형에는 Δ 가 명시적으로 등장하지 않으며 ρ, Ω, η 등 단계당 비율만 남는다.

════ (다) 갈래 1 / 갈래 2 의 차이와 이중 누적 계수 ════

1. 객체 유형
 갈래 1: [안] = 실수 인과 흔적 1개(ω=0 채널), [밖] = 시간 적분. 구동 D₁ 은 스파이크 시각에만 비영인 순간 객체. 각 쌍은 '나중 스파이크' 시각에 정확히 1회 계수된다. 인과 비대칭의 소재 = 어느 쪽이 순간이고 어느 쪽이 필터인가 + 부호 (위상 없음).
 갈래 2: [안] = 양쪽 뱅크 흔적의 켤레곱 × Ŵ(ω). 어느 시각에나 비영. 이미 쌍 합(누설 2/τ_z, 창 협착 W̃) 을 수행한 누적 객체. 인과 비대칭의 소재 = ψ(ω) = arg Ŵ(ω) (홀 창 ⇔ ψ = ±π/2 모든 ω).
2. 동치 조건: (i) 뱅크가 ω 를 연속으로 덮음, (ii) τ_z → ∞, (iii) Q 를 끝점 T 에서 단 한 번 읽음. 셋이 모두 성립할 때만 Q(T) = Σ W(s_fg) = 갈래 1 의 결과. 하나라도 깨지면 다르다.
3. 이중 누적 계수 (갈래 2 위에 [밖] 을 다시 걸 때, 각 쌍이 양쪽 흔적이 살아있는 동안 반복 계수되는 인자):
 연속: κ₂ = ∫_0^∞ e^{−2u/τ_z}du = τ_z/2
 이산: κ₂ = Σ_{n≥0} ρ_z^{2n} = 1/(1−ρ_z²) ≈ τ_z/(2Δ)
 정규화 뱅크(입력 전인자 √(1−ρ_z²)) 에서는 켤레곱에 (1−ρ_z²) 가 붙어 κ₂ = 1. 계수는 사라지지만 창 협착 ρ_z^{|m|} 과 Q 의 누설 ρ_z² 은 그대로 남는다.
 결과: 갈래 2 + [밖] 적분기 = 갈래 1 with W → κ₂·W̃,  W̃(s) = e^{−|s|/τ_z}W(s),  τ̃± = (1/τ± + 1/τ_z)^{−1}.
 균형 이동: Ŵ̃(0) = A₊τ̃₊ − A₋τ̃₋. 원래 균형 A₊τ₊ = A₋τ₋ 는 τ₊ = τ₋ 일 때만 보존된다.
 [밖] 이 EMA(η) 인 경우: 저역 2단(ρ_z² 안, η 밖). 단일 쌍의 시간 질량 = κ₂W̃ (EMA DC 이득 1), 최고치 ≈ [η/(1−ρ_z²)]·W̃ (η ≪ 1−ρ_z², 느린 EMA) 또는 ≈ W̃ (빠른 EMA).
4. 뱅크가 실현하는 창 (고립 쌍, [밖] 적분기 후):
 연속: W_bank(s) = κ₂ Σ_ℓ c_ℓ |Ŵ_ℓ| e^{−|s|/τ_z} cos(ω_ℓ s + ψ_ℓ)
 이산: W_bank[m] = κ₂ Σ_ℓ c_ℓ |Ŵ_ℓ| ρ_z^{|m|} cos(Ω_ℓ m + ψ_ℓ)
 |Ŵ_ℓ| 없이 ψ_ℓ 만 남기면 창 = ρ_z^{|m|} × p 항 삼각다항식. ψ_ℓ = −π/2 전부이면 ρ_z^{|m|}Σ_ℓ c_ℓ sin(Ω_ℓ m): 홀이고 m=0 에서 0, 표준 창의 0 근방 점프는 p 가 클 때만 근사된다(깁스). 채널 간격 ΔΩ 의 별칭(주기 2π/ΔΩ) 은 ρ_z^{|m|} 이 그 지연까지 감쇠해야 억제된다.
5. 통계적 효력: Σ_k Q[k] = κ₂ Σ_쌍 W̃ 이므로 갈래 2 의 [밖] 합은 쌍 수만큼의 독립 표본만 가진다. κ₂ 는 규모만 키우고 표본 수(신호대잡음) 는 늘리지 않는다.

════ (라) 위상 잠금 / 상쇄의 스케일링 ════

설정: 바깥 지표 k 에서의 단일 채널 기여 g_k = R cos(Δφ_k + ψ), Δφ_k = φ_i − φ_j. STDP 쪽에서 '잠김' = 바깥 축에 걸쳐 시간차 s 가 일정(Δφ = ω s 상수), '거짓' = s 가 표류하거나 무작위.
(1) 잠김 (Δφ_k = Δφ₀): 적분기 Σ_k g_k = K R cos(Δφ₀+ψ) ∝ K.  EMA: w → R cos(Δφ₀+ψ), K 무관(1/η 후 포화). 부호는 ψ 와 Δφ₀ 가 정한다 — STDP 에서 잠김은 '관계 있음' 이 아니라 '인과 방향에 따른 LTP 또는 LTD' 이다.
(2) 결정론적 진동 (Δφ_k = Δφ₀ + Ω_b k): 적분기 |Σ_k g_k| ≤ R/|sin(Ω_b/2)| ≈ 2R/|Ω_b| — K 에 무관하게 유계. 억제비(잠김/진동) ≈ K|Ω_b|/2, 조건 K ≫ 2π/|Ω_b|.  EMA: |H(Ω_b)| = η/√(η² + 2(1−η)(1−cos Ω_b)) ≈ η/√(η²+Ω_b²), 억제비 ≈ |Ω_b|/η (Ω_b ≫ η), 조건 η ≪ |Ω_b|; K 를 1/η 이상 늘려도 개선 없음. 갈래 2 의 자체 누설(ρ_z²) 만으로도 같은 꼴: 억제비 ≈ |Ω_b|/(1−ρ_z²).
(3) 무작위 위상 (i.i.d. 균등): 적분기 평균 0, 표준편차 R√(K/2), 억제비 √(2K).  EMA: 분산 = η/(2−η)·R²/2, 억제비 ≈ 2/√η. 갈래 2 에서는 K 대신 유효 쌍 수 N_쌍 (연속: ≈ T/τ_z 단위의 독립 표본).
(4) STDP 고유의 진술: 시간차 s(t) 가 속도 v 로 창 전체를 훑고 지나가면 적분기 기여 = (1/v)∫W ds = Ŵ(0)/v. 즉 '부호 진동의 상쇄' 는 STDP 에서 창의 DC 가 0 이라는 조건(Ŵ(0) = A₊τ₊ − A₋τ₋ = 0, 홀 창) 과 같은 진술이며, 바깥 적분은 창 전체를 표본화하는 장치일 뿐이다. 둘 다 필요: Ŵ(0) ≠ 0 이면 어떤 길이의 적분도 상쇄하지 못한다.
(5) 율 곱 표류: 독립 포아송에서 E[Δw] = Ŵ(0)ν_iν_j T ∝ T — 잠긴 신호와 같은 차수. 상쇄 조건은 (4) 와 동일. 갈래 2 에서는 E[conj(Z̃_j)Z̃_i] = conj(E Z̃_j)E Z̃_i 의 위상차가 0 (공통 위상 atan(ωτ_z)) 이므로 모든 채널에 '잠긴 것처럼 보이는' 성분이 존재하고, 그 합 = ν_iν_j κ₂ Ŵ̃(0) = ν_iν_j Σ_ω Re Ŵ(ω)·τ_z²/(1+ω²τ_z²). 0 이려면 Re Ŵ 가 로렌츠 가중으로 상쇄되어야 하며, 충분조건은 ψ(ω) = ±π/2 (모든 채널). 바깥 적분은 이것을 없애지 못한다.
(6) 신호대잡음: 잠긴 쌍 N 회 ⇒ Δw = N W(s₀) ∝ T; 무상관 요동 ∝ √(ν_iν_jT∫W²) ⇒ SNR ∝ √T (Ŵ(0)=0 일 때). 이 √T 는 쌍 사건의 독립성에 의존하며, 갈래 2 의 k 축 표본은 τ_z 동안 상관되어 있다.
(7) 뱅크 위상차의 정체: 고립 쌍에서 φ_i(ω) − φ_j(ω) = ω·s (이산 Ω·m). 여러 스파이크가 창 안에 겹치면 위상차는 시간차들의 가중 원형 평균. STDP 쪽에서 위상차는 시간차에 ω 를 곱한 것이다.
```

### 관점 1 — 분해적

핵심 대수 결과. (1) 통합적 대응의 골격: C2(z 뱅크)+C4(a^β)+C6(EMA) ↔ S3(Z 뱅크)+S2(arg Ŵ)+S5(누설 적분). conj(z_t)z_n 을 전개하면 쌍 (k',k'') 에 ρ_j^{2k−k'−k''}e^{iω_j(k''−k')} 가 붙어, 바깥 EMA 후 블록 지연 s=k_post−k_pre 에 대한 실효 창 W_arch(s)=Σ_j c_j ρ_j^{|s|}cos(ω_j s−β_j) 가 생긴다. 이것은 STDP 창의 감쇠 코사인 급수이며 β_j=−arg Ŵ(ω_j), β_j=+π/2 가 반대칭(인과) STDP 에 해당한다. (2) 따라서 P1 은 S6 식 표면에서만 성립한다: ω_j≠0 이면 φ̌_t−φ̌_n 은 시간 지연 위상 ω_j s 와 내용 위상차 φ_u,n−φ_u,t 의 합이다. 순수 내용 위상 해석은 ω_j=0 을, 순수 STDP 해석은 B=0(u 실수) 을 요구한다. (3) P2 의 상쇄는 EMA 의 저역 통과 η/√(η²+Ω²) 로 정확히 표현되지만, 진동율 Ω 의 출처는 u 의 내용 위상 회전이며 STDP 에는 이에 해당하는 대상이 없다(ω_j 는 쌍 곱에서 소거). (4) 대응 없음: 정규화 3종(û,ẑ,v̂), |Ŵ(ω_j)|, D(Δ), θ_j·Δ, ψ_j, 읽기 커널 a 와 λ 혼합, agree(두 창의 곱), Φ(문턱·리셋 대신), 경계 쌍선형, detach. (5) 구조적 차이: STDP 는 하나의 S 가 가소성 신호이자 전송 신호인데 아키텍처는 u(가소성)≠v(전송). (6) w 첫 블록은 w(0) 없이 tgt(1) 을 1/η 배 과대 가중한다.

### 관점 2 — 통합적

최소 단위가 실제로 일치하는 곳: (1) 흔적 z 재귀 = 감쇠 주파수 뱅크 Z_i(ω;k) 의 Δk=1 이산화 (μ_j = ρ_j e^{iω_j} ↔ e^{−1/τ}e^{∓iω}, 초기조건 z(0)=0 포함); (2) β_j ↔ −arg Ŵ(ω_j) (짝/홀 분해, 반대칭성 a^β_nt: β→−β 도 일치); (3) 복합체 a^β ↔ '양쪽 필터' 형 Σ_ω Re[conj(Z_post) Ŵ Z_pre], 전개하면 블록 지연 s 에 대한 푸리에 합성 창 W̃(s,r) = Σ_j (1−ρ_j²) ρ_j^r cos(ω_j s + β_j) 를 가진 최근성 가중 쌍 규칙 — 표준 STDP(한쪽 순간·한쪽 필터, 최근성 없음)가 아니라 그 변형; (4) w EMA ↔ 누설 있는 바깥 적분(누설 = 표준 밖), P2 의 상쇄 기제는 양쪽 다 저역통과(차단 η vs 1/K)로 동일하게 성립; (5) 전달 o = Σ a^eff v ↔ I = Σ w S (κ=δ) 는 λ=1 에서만, 주입 ↔ I_ext(DC), 블록 k ↔ t, 가중치 공유 ↔ 자율성, h ↔ V, h+f ↔ 누설 없는 막전위 적분, softplus(g) ↔ A 배율. 대응 없음: 읽기 커널 전체(C3: 무기억 û 위상, θ·Δ, ψ, D, a — STDP 는 누적 w 로만 전달), 세 정규화(û, ẑ, v̂), agree 와 G(쌍별 3인자), λ 혼합과 a^eff, Φ(사건 없는 노름 제한 — 문턱·리셋과 유형 불일치), 경계 쌍선형, detach, 로짓 읽기, w 첫 블록(자유 w(0) 부재). 유형 불일치로 특히 주의할 점: 아키텍처에는 사건 S 가 전혀 없고(흔적·전달·구동 입력이 모두 선형 읽기), 흔적 입력 u_{t,j} 가 뱅크별 복소수(STDP 는 뱅크 공통 실수 사건), 같은 z 가 전·후 양쪽에 쓰여 τ₊=τ₋ 강제, w 는 활동 수준이 지워진 정규화 흔적의 위상 정합만 누적한다.

### 관점 3 — 최소단위

근거: 프롬프트의 정본 자리표시자(${fwd.equations} 등)가 비어 있어 본문의 전사본 명세만을 근거로 함. 파일 열람·수치 인용 없음.

핵심 결과 (★): η→0(무누설 합), ẑ 정규화 제거, D=1, θ=0 에서
Σ_k Re[e^{iβ_j} conj(z_t(k)) z_n(k)] = Σ_{k',k''} ρ_j^{|k'−k''|} Re[e^{i(β_j + ω_j(k'−k''))} conj(u_t(k')) u_n(k'')].
즉 {C2 z 재귀(ρ,ω,√(1−ρ²),첫 블록)} + {C4 β_j, a^β 의 Re Σ_j 구조} + {C6 w EMA} 를 묶은 복합체가 STDP 의 {S3 뱅크 Z(σ,ω;t)} + {S2 Ŵ 위상} + {S4 양쪽 필터형 Σ_ω Re[Ŵ Z_j* Z_i]} + {S5 바깥 적분} 복합체와 통합적으로 대응하며, 시차 s = k'−k'' 위의 유효 창은 Σ_j ρ_j^{|s|} cos(ω_j s + β_j) (짝 포락 × 짝/홀 진동). 이 대응은 누적 수준에서만 성립하고, 순간 tgt(k) 는 STDP 의 순간 증분 x_i S_j − y_j S_i 와 다른 객체다.

정확 일치 조건: (1) u 실수(B=0) — 아니면 창 인수에 주소 위상차 φ_n(k'')−φ_t(k') 가 더해져 시차가 아닌 항이 창을 이동(P1); (2) ẑ 미정규화 — 정규화는 교차 스펙트럼을 결맞음으로 바꿔 율 의존을 지움(P2 의 '위상 잠김만 남음' 은 이 정규화의 효과이지 표준 STDP 의 성질이 아님); (3) agree ≡ 1 (C=1, v ≥ 0 이면 자동); (4) λ = 1; (5) η → 0 (누설은 표준 밖). 또한 같은 흔적이 전·후 역할을 모두 맡으므로 τ₊ = τ₋ 가 강제되고, 성분별 진폭 자유도(|Ŵ(ω_j)|)가 없어 표준 홀 창 sgn(s)e^{−|s|/τ} 는 급수 근사만 가능.

P2 의 STDP 언어 번역: 누적 Σ_k Re[e^{iβ_j} conj(ẑ_t)ẑ_n] 은 ω_j 에서의 (정규화된) 교차 스펙트럼 누적이며, 위상차 부호가 k 에 걸쳐 진동하면 상쇄되고 잠기면 가산된다. 단, 같은 k 의 두 흔적 위상차에서 ω_j 는 상쇄되므로 진동은 주소 u_t(k) 의 k 비정상성에서만 발생하고, '잠김' 은 복소 주소의 정적 위상 오프셋일 수 있어 STDP 의 시간 결맞음과 같은 뜻이 아니다.

대응 없음: C1 의 u(복소 유형), û, r̂, φ̂, ε; C3 전부(θ·Δ, ψ, Re, Σ_j, D, a — 필터 전 순간 커널과 공간 사전); C2 ẑ 정규화; C5 v̂, agree, G; C6 w 첫 블록(활동 독립 w(0) 부재), λ; C8 경계 쌍선형, detach, 로짓. 분해적: ρ↔τ, ω↔ω, √(1−ρ²)↔A± 자리(자유도 없음), 첫 블록↔x(0)=0, β↔arg Ŵ, softplus(g)↔|A±|, a^eff↔w_ji 자리, v↔(κ*S_i), o↔I_j, f↔I(결합 행렬 제외), h+f↔막 적분(무누설), Φ↔포화(리셋 아님), 주입↔I_ext, k↔t, 가중치 공유↔자율성. 상태 h 는 {h, h+f, Φ, 갱신} 복합체로서만 V_j 와 통합적 대응(스파이크·문턱·리셋·누설 없음).

### 관점 4 — 두적분

[대응 성립 축] (1) 흔적: z 재귀·ρ_j·ω_j·첫 블록 z(0)=0 ↔ 인과 주파수 뱅크 Z_i(ω;t)=∫_0^∞ e^{−s/τ}e^{−iωs}S_i(t−s)ds 및 초기조건 (연산자 동일, 입력 유형만 다름). (2) 창 위상: β_j ↔ arg Ŵ(ω_j); cos β_j ↔ 짝창(Re Ŵ), sin β_j ↔ 홀창(Im Ŵ). (3) 쓰기 창 a^β ↔ S4 의 '양쪽 필터' 형태 Σ_ω conj(Z_j)ŴZ_i (통합적). 비누설·실수 입력·정규화 제거 가정에서 바깥 누적과 합쳐 쌍 규칙으로 환원: 유효창 W_j(s)=softplus(g)·ρ_j^{|s|}cos(ω_j s−β_j). (4) w EMA ↔ 바깥 적분 (누설 −w/τ_w 는 표준 밖). (5) o=Σ_n a^eff v_n ↔ I_j=Σ_i w_ji S_i(κ=δ), 주입 ↔ I_ext, h+f ↔ 완전 적분기(τ_m→∞), Φ ↔ 포화, k ↔ t(창 인자 역할 제외), 가중치 공유 ↔ 자율성.
[대응 없음 — 유형 불일치] 주소 경로 전체(u 복소 판독, û·r̂·φ̂, ε): STDP 위상은 전부 ω×시각차인데 φ̂ 는 W_C 두 판독의 비율(P1). 읽기 커널 전체(θ·Δ, ψ, D, Σ_j·Re 의 읽기 역할, a): 순간×순간 유사도가 전달 가중에 들어가는 구조는 STDP 에 없음. λ 혼합·a^eff(λ=1 에서만 w 와 일치). agree·G: 쌍당 이중선형 곱이 두 개(4차) — 표준은 하나. 정규화 세 곳(û, ẑ, v̂)과 √(1−ρ²): 율(크기) 정보 소거 — STDP 의 율 의존성과 배치. 경계 쌍선형(2차 자기항, 표준 밖 QIF 류), w 첫 블록(활동 무관 w(0) 부재), detach·로짓(학습 절차 객체).
[구조적 결론] (a) 표준 구동 x_i S_j − y_j S_i (한쪽 순간·한쪽 필터) 가 아키텍처에 없음 — 아키텍처는 순간×순간(a, agree) 과 필터×필터(a^β) 만 가짐. (b) 유효창은 대칭 포락선·진동형이라 표준 지수 비대칭창(τ₊≠τ₋)을 한 뱅크로 못 만들고, 재현에 필요한 뱅크별 진폭 |Ŵ(ω_j)| 가 파라미터가 아니라 상태 ř_{t,j}ř_{n,j} 임. (c) STDP 의 단일 출력 S_j 가 주소 u(학습 커널) 와 값 v(전달·agree) 로 분리됨. (d) P2 의 상쇄는 STDP 에서 Ŵ(0)=0 (A₊τ₊=A₋τ₋) 조건의 무상관 쌍 상쇄와 형식상 닮았으나, 아키텍처의 부호 교대는 시각차 분포가 아니라 Δφ̌ 의 블록 축 표류에서 오므로 같은 조건으로 환원되지 않음.

### 관점 5 — 전달/가소성

(전제: 렌즈 지시문 ${L.prompt} 과 정본 삽입란이 비어 있어 P1~P4 와 전사본만으로 작업했다. 파일 열람·수치 인용 없음.)

1. 대응되는 사슬 (분해적/통합적): u → z (누설 단시간 푸리에 뱅크, C2-1~3) → Σ_j Re[conj(ẑ_t)ẑ_n e^{iβ_j}] (양쪽 필터 STDP 구동, C4-2; β_j = arg Ŵ(ω_j), C4-1) → w 의 EMA (누설 바깥 적분, C6-1) → a^eff (전달 가중치, C6-4) → o = Σ a^eff v (I_j = Σ w (κ*S), C7-1) → h+f, Φ (막전위 적분·포화, C7-3/4). 이 사슬이 정확히 STDP 쌍 규칙과 일치하는 조건: u_{t,j}(k) = g_j s_t(k), s_t 실수 (W_C = g⊗w_cᵀ, B=0); 정규화 û·ẑ·v̂ 없음(율 의존 복원); agree ≡ 1; λ = 1; D ≡ 1, θ = 0; η → 0; τ_bank ≫ τ±; u 와 v 가 같은 스칼라의 함수.

2. P1 의 정정: 읽기 커널 a 에는 시간차가 없다(k′ = k″ = k). 그러나 쓰기 창 a^β 는 흔적 쌍곱 전개 conj(z_t)z_n = (1−ρ²)Σ_{k′,k″} ρ^{2k−k′−k″} e^{iω_j(k′−k″)} conj(u_t(k′))u_n(k″) 를 통해 ω_j(k′−k″) — 두 토큰 입력의 블록 차 — 를 포함한다. u 가 실수이면 Σ_j |Ŵ_j| cos(ω_j s + β_j) = W_bank(s) 로 STDP 창 자체가 된다. 즉 '커널 안에 Δt 가 없다'는 a 에만 참이고, a^β 는 Δt 를 뱅크 위상으로 담고 있다.

3. P2 의 STDP 판: ∫dt Σ_ω Re[Z_j*(ω;t) Ŵ(ω) Z_i(ω;t)] 에서 상대 위상이 표류하는 쌍은 ∫e^{i(ω_i−ω_j)t}dt → 0 으로 상쇄되고, 잠긴 쌍은 T·|Ŵ|cos(Δφ + arg Ŵ) 로 선형 누적된다. 아키텍처의 EMA 는 이 바깥 적분의 누설판이며 상쇄 조건은 1/η ≫ 2π/|Δω|.

4. 대응 없음 (16개): û, r̂, φ̂ (비시간 위상·모양 변하는 펄스·율 소거), ẑ (율 정규화), θ_j·Δ (반대칭·j 자유 → 지연 아님), ψ_j, D(Δ), 읽기 커널 a 전체, v̂, agree, G (제2 쌍 커널의 곱), λ 혼합, f = W_shᵀ o, 경계 쌍선형, 세그먼트 detach, 로짓 읽기. 공통 요구: STDP 는 뉴런당 스칼라 신호 1개·쌍 커널 1개·전달은 누적 가중치만·공간 없음·규칙 학습 없음.

5. 통합적 대응 (3개): √(1−ρ²) 는 (1−ρ_j²)‖(W_C)_j‖² 복합체로서만 |Ŵ(ω_j)| 에 대응(전용 매개변수 부재); a^β 는 복합체로서 양쪽 필터 구동에 대응; o 는 복합체로서 I_j 에 대응.

6. 유형 주의: φ̂(비시간) vs 뱅크 위상(시간) — 다른 자리; a(순간, 비적분) vs w(누적) — 다른 자리; agree(쌍 커널) vs 삼인자 M(전역)·전압 인자(한쪽) — 다른 자리; D(승산 쌍 상수) vs w(0)(가산) — 다른 자리.

### 관점 6 — 부호/크기
