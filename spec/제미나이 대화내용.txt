]

[

S_t^{(r)}

\in

\mathbb C^{p\times d}

]

현재 토큰은 자신의 복소 key와 실수 hidden state의 외적으로 기록됩니다.

[

k_t h_t^\top

]

과거 기록은 크기가 감쇠하지 않고 위상만 회전합니다.



4. 위상 측정과 출력

현재 query로 누적 상태를 읽습니다.



[

f_t^{(r)}

\frac{1}{t\sqrt p}

\operatorname{Re}

\left[

\left(q_t^{(r)}\right)^\dagger

S_t^{(r)}

\right]

]

[

f_t^{(r)}\in\mathbb R^d

]

두 스케일은 구조적으로 정해집니다.



(1/\sqrt p): 복소 내적의 차원 스케일

(1/t): 완전-prefix 그래프의 측도 정규화

특히 (1/t)를 사용하면:



무작위 위상 합은 (O(\sqrt t)/t=O(t^{-1/2}))

정렬된 위상 합은 (O(t)/t=O(1))

이 됩니다.

따라서 모델이 원래 의도한

[

\boxed{

\text{비정렬 잡음은 사라지고 정렬된 패턴만 남는 현상}

}

]

이 정확한 스케일 법칙으로 나타납니다.



5. 재귀 깊이 업데이트

(f_t^{(r)})를 새로운 표현 자체로 사용하지 않고, hidden state의 변화율로 사용합니다.



[

\boxed{

h_t^{(r+1)}

h_t^{(r)}

+

\frac1R f_t^{(r)}

}

]

잔차 연결은 별도 보조 장치가 아닙니다.

이는 다음 연속 동역학을 총시간 1 동안 (R)번 Euler 적분한 것입니다.



[

\frac{\partial h_t}{\partial \tau}

f_t(h)

]

따라서 (1/R) 이외의 step-size 하이퍼파라미터는 두지 않습니다.



6. 전체 attention weight 전개

상태를 전개하면,



[

S_t^{(r)}

\sum_{n=1}^{t}

U^{t-n}

k_n^{(r)}

\left(h_n^{(r)}\right)^\top

]

입니다.

따라서



[

f_t^{(r)}

\sum_{n=1}^{t}

a_{tn}^{(r)}h_n^{(r)}

]

이고,



[

\boxed{

a_{tn}^{(r)}

\frac{1}{t\sqrt p}

\operatorname{Re}

\left[

\left(q_t^{(r)}\right)^\dagger

U^{t-n}k_n^{(r)}

\right]

}

]

입니다.

성분별로 쓰면,



[

\begin{aligned}

a_{tn}^{(r)}

\frac{1}{t\sqrt p}

\sum_{j=1}^{p}

&|z_{t,j}^{(r)}|

|z_{n,j}^{(r)}|\

&\cos

\left(

\arg z_{n,j}^{(r)}

-\arg z_{t,j}^{(r)}

-\psi_j

-(t-n)\theta_j

\right)

\end{aligned}

]

입니다.

즉, 하나의 edge weight가 다음 네 요소로 완전히 분해됩니다.



현재 토큰의 채널 진폭

과거 토큰의 채널 진폭

두 토큰의 의미 위상차

시간 지연에 따른 회전 위상

7. 하나의 연산에서 반응과 확산이 같이 나온다

행렬 (A^{(r)}=[a_{tn}^{(r)}])를 정의하면,

[

F^{(r)}=A^{(r)}H^{(r)}

]

입니다.

각 토큰에서는 다음 항등식이 성립합니다.

[

\begin{aligned}

f_t^{(r)}

={}&

\sum_{n\le t}a_{tn}^{(r)}

\left(

h_n^{(r)}-h_t^{(r)}

\right)\

&+

\left(

\sum_{n\le t}a_{tn}^{(r)}

\right)

h_t^{(r)}

\end{aligned}

]

따라서



[

\boxed{

f_t

\underbrace{

\sum_n a_{tn}(h_n-h_t)

}{\text{signed graph diffusion}}

+

\underbrace{

d_t h_t

}{\text{local gain/reaction}}

}

]

입니다.

여기서

[

d_t=\sum_n a_{tn}

]

입니다.

즉, 별도 FFN 반응항을 추가하지 않아도 원래 attention 출력 자체가 정확히

[

\boxed{

\text{확산항}+\text{반응항}

}

]

으로 분해됩니다.



8. 확산항의 작동

[

\sum_n a_{tn}(h_n-h_t)

]

에서:



(a_{tn}>0): 두 토큰의 표현 차이를 감소

(a_{tn}<0): 두 토큰의 표현 차이를 증가

(a_{tn}\approx0): 두 토큰이 거의 상호작용하지 않음

따라서 동일한 attention graph 안에서 다음이 모두 가능합니다.

[

\boxed{

\begin{cases}

\text{positive edge} & \text{확산}\

\text{negative edge} & \text{반확산}\

\text{zero edge} & \text{분리}

\end{cases}

}

]

의미 없는 입력에서는 위상들이 상쇄되어 전체 그래프가 약한 소산 상태에 머뭅니다.

구조화된 패턴이 들어오면 특정 edge 집단만 강한 양수 또는 음수 값을 가지며, 해당 그래프 모드가 선택적으로 보존되거나 증폭됩니다.



9. 반응항의 작동

[

d_t h_t

]

는 현재 토큰의 상태에 대한 local gain입니다.

[

d_t<0

]

이면 현재 표현이 억제되고,

[

0<d_t<1

]

이면 약하게 유지되며,

[

d_t>1

]

인 방향에서는 증폭됩니다.

특히 자기항은

[

a_{tt}h_t

]

이고,



[

\boxed{

a_{tt}

\frac{1}{t\sqrt p}

\sum_{j=1}^{p}

\cos(\psi_j)

|z_{t,j}|^2

}

]

입니다.

따라서 자기항 전체는

[

\boxed{

\left[

\frac{1}{t\sqrt p}

\sum_j

\cos(\psi_j)|W_Ch_t|_j^2

\right]h_t

}

]

가 됩니다.

이는 (h_t)에 대한 정확한 factorized cubic입니다.

채널별로:

[

\cos\psi_j>0

]

이면 그 채널은 진폭 의존적 흥분을 만들고,

[

\cos\psi_j<0

]

이면 진폭 의존적 억제를 만듭니다.

따라서 (\psi)가 기존 신경 모델의 흥분성·억제성 채널에 대응합니다.



10. 이 최소 모델에서 스파이크가 만들어지는 과정

재귀 깊이 (r)를 내부 계산 시간으로 보면 다음 순서가 가능합니다.



1. 휴지 상태

위상이 비정렬돼 attention weight가 상쇄됩니다.

[

d_t\approx0

]

[

|HAH|<1

]

토큰 차이는 확산되고 hidden state 변화는 작습니다.



2. 입력 누적

과거의 (k_nh_n^\top)가 (S_t) 안에서 회전하며 보존됩니다.

visible 출력은 작아도 위상 정보는 남습니다.



3. 임계 정렬

특정 query가 과거 key들의 회전 위상과 맞습니다.

[

d_t>0

]

또는 특정 centered graph mode에서

[

|HAH|>1

]

이 됩니다.



4. 증폭

현재 hidden state가 커지면 자기항이 3차로 커집니다.

[

a_{tt}h_t

\propto

|W_Ch_t|^2h_t

]

5. 억제·회복

증폭된 상태는 다음 재귀 단계의 (z,q,k,A)를 바꿉니다.

그 결과:



억제성 (\cos\psi_j<0) 채널이 강해지거나

시간 회전으로 위상 정렬이 풀리거나

graph mode가 다시 (|HAH|<1)로 내려갑니다.

그러면 출력은 다시 소산 영역으로 복귀합니다.

이 모델에서 스파이크는 명시적 0/1 이벤트가 아니라,

[

\boxed{

\text{특정 그래프 모드의 일시적인 에너지 급상승}

}

]

입니다.

연산의 직교성 (Orthogonality in Computation):
반응항의 해석적 매핑은 벡터 차원에서의 스칼라 연산으로 끝나며, 확산항의 선형 누적 연산과 충돌하지 않습니다. 추가적인 텐서 투영이나 파라미터 증설 없이 동역학의 구조만으로 안정을 취합니다.

결론적으로, 연산자 분할(Operator Splitting)은 외부의 활성화 함수나 LayerNorm을 씌우지 않고도, 물리계 본연의 해석적 경계를 네트워크 방정식에 내재화하여 닫힌 위상 공간 내부에서만 비선형성을 최적화하도록 강제하는 가장 이론적으로 완전한 해법입니다.

유저의 직관이 정확합니다. 연산자 분할(Operator Splitting)을 통해 치명적인 붕괴(Collapse)는 완벽히 제어할 수 있지만, 아키텍처 자체의 최소주의적 설계로 인해 표현력(Expressivity)과 상황적 추론(In-Context Reasoning) 능력에서 구조적인 병목(Bottleneck)이 발생합니다.

특히 지적하신 '입력 비의존적 파라미터(Input-independent Parameter)' 문제를 포함하여, 이 모델이 학습의 한계에 부딪힐 수밖에 없는 이론적 지점은 크게 세 가지로 압축됩니다.
