# STDP 적분의 주파수 영역 표현과 위상차 커널의 대응

> 2026-09-08~09. 이 문서는 **유도**만 담는다. 실측은 §11, 미해결은 §12, 내가 도중에 틀린 것들은 §13.
> 결론 한 줄: **바깥(시간 누적)은 정의상 같고, 안쪽(창의 합성곱)을 주파수 영역으로 옮기면
> 우리 커널과 항별로 일치한다. 자명하지 않은 대응은 `j ↔ ω` 하나뿐이고, 잔차 흔적이 그것을 가정에서 정의로 바꾼다.**

---

## §1. 규약

```
변환      f̂(ω) = Σ_m f(m) e^{-iωm}            (블록 축은 이산 → DTFT)
실수성    f 실수  ⟹  f̂(-ω) = f̂(ω)*
교차상관  C(s) = Σ_t S_pre(t) S_post(t+s)
n = pre (원천),  t = post (표적).    전달이 f_t = Σ_n a_tn v_n 이므로.
```

## §2. STDP 를 두 층으로 — 재배열뿐, 가정 없음

```
Δw = ΣΣ W(t′−τ) · S_n(τ) · S_t(t′)
```

바깥 변수를 **post 시각**으로 잡고 `u = t′ − τ` 로 치환하면

```
Δw = Σ_k  S_t(k) · [ Σ_u W(u) · S_n(k−u) ]
     └바깥┘ └post 지금┘ └──── pre 의 필터된 이력 = 흔적 x_n(k) ────┘

     바깥 = 절대 시간 위의 누적
     안쪽 = 창이 pre 이력에 거는 합성곱
```

이중합을 post 시각 기준으로 정렬하면 안쪽이 **자동으로** 합성곱이 된다.
"흔적 × 지금" 은 모형 선택이 아니라 재배열의 결과다.

(pre 시각 기준으로 정렬하면 다른 가지가 나온다. 창을 `W = W₊Θ(s) + W₋Θ(−s)` 로
쪼개 각 조각을 "나중에 온 쪽" 기준으로 정렬한 것이 표준 두-흔적 형태다.)

## §3. 우리 모델도 같은 두 층

```
바깥 :  w(k) = δ Σ_m (1−δ)^m · G(k−m)
안쪽 :  G_tn(k) = D(Δ) Σ_j r_{n,j}(k) r_{t,j}(k) cos( φ′_{t,j}(k) − φ′_{n,j}(k) + β_j )
```

**바깥끼리는 볼 것이 없다.** 둘 다 같은 축(절대 시간) 위의 누수 누적이다.
대응시킨 게 아니라 원래 같은 연산이다.

⟹ 질문 전체가 **"안쪽 두 개가 같은 연산인가"** 로 좁혀진다.

## §4. 안쪽을 주파수로 — 유도

### 보조정리 A (상관 정리)

```
Ĉ(ω) = Ŝ_pre(ω)* · Ŝ_post(ω)
```

증명. `Ĉ(ω) = ΣΣ S_pre(t) S_post(t+s) e^{-iωs}`. `u = t+s` 치환:
`= [Σ_t S_pre(t) e^{+iωt}][Σ_u S_post(u) e^{-iωu}] = Ŝ_pre(-ω) Ŝ_post(ω)`.
`S_pre` 실수이므로 `Ŝ_pre(-ω) = Ŝ_pre(ω)*`. ∎

### 보조정리 B (플랑슈렐, 실함수 쌍)

```
f, g 실수  ⟹  Σ_s f(s) g(s) = (1/2π) ∫ f̂(ω)* ĝ(ω) dω
```

증명. `g(s) = (1/2π)∫ĝ(ω)e^{iωs}dω` 를 대입하고 `s` 합을 먼저 하면
`(1/2π)∫ĝ(ω) f̂(-ω) dω`, `f` 실수이므로 `f̂(-ω) = f̂(ω)*`. ∎

### 본 유도 — 성분합이 시간 이중합을 복원한다

토큰별 단시간 변환을 정의한다:

```
Z_t(j;k) = Σ_{m≥0} γ^m · x_t(k−m) · e^{-i ω_j m}
```

그리고 다음을 **전개해서** 무엇인지 확인한다 (pre 쪽을 켤레):

```
Σ_j  Z_n(j;k)* · Ŵ_j · Z_t(j;k)

 = Σ_j Ŵ_j · Σ_{m,m′} γ^{m+m′} · x_n(k−m′) · x_t(k−m) · e^{i ω_j (m′−m)}

 = Σ_{m,m′} γ^{m+m′} · x_n(k−m′) · x_t(k−m) · [ Σ_j Ŵ_j e^{i ω_j (m′−m)} ]
                                                └────── = W(m′−m) ──────┘
                                                          역변환
```

`(k−m′)` 은 pre 시각, `(k−m)` 은 post 시각이고
`m′ − m = (k−m) − (k−m′) = post시각 − pre시각 = s` 이므로

```
┌────────────────────────────────────────────────────────────────────┐
│  Σ_j Z_n(j)* Ŵ_j Z_t(j)                                            │
│      = Σ_{m,m′} γ^{m+m′} · S_n(pre시각) · S_t(post시각) · W(s)      │
│        └────────── §2 의 이중합 그 자체 (창 γ 로 자른) ──────────┘  │
└────────────────────────────────────────────────────────────────────┘
```

**성분에 대한 합 `Σ_j` 가 시간 쌍에 대한 이중합 `Σ_{m,m′}` 을 복원한다.**
새 연산이 아니라 이중합을 주파수 기저에서 쓴 것이다.

## §5. 대응 사전

```
STDP 안쪽 :  Γ(k) = Re Σ_j  Z_n(j;k)*   · Ŵ_j        · Z_t(j;k)
우리 안쪽 :  G(k) = Re Σ_j  ẑ_{n,j}(k)* · e^{-iβ_j}  · ẑ_{t,j}(k)   × D(Δ)
```

| STDP (주파수 영역) | 아키텍처 | 근거 |
|---|---|---|
| 절대 시간 누적 `Σ_k` | `Σ_m (1−δ)^m` | **항등** |
| 주파수 `ω` (>0) | 성분 인덱스 `j` | **가정** — §8(A) |
| `∫₀^∞ dω` | `Σ_j` | 가정 |
| `\|Z_pre\|·\|Z_post\|` | `r_{n,j} · r_{t,j}` | **부분** — 정규화로 총 크기 소거 |
| `Δθ(ω;k)` | `Δφ′_j(k)` | 가정과 함께 |
| `ψ(ω) = −arg Ŵ(ω)` | `β_j` | **항등** — 창의 위상 스펙트럼 |
| `\|Ŵ(ω)\|` | `D(Δ)·g` — **`j` 의존성 없음** | **불일치** — §12(1) |

## §6. 정리 — 창의 패리티 ⟺ 변환의 실/허

```
W 짝함수 (W(−s) = +W(s))  ⟺  Ŵ(ω) ∈ ℝ   ⟺  β ∈ {0, π}
W 홀함수 (W(−s) = −W(s))  ⟺  Ŵ(ω) ∈ iℝ  ⟺  β = ∓π/2
```

증명. `Ŵ(ω) = Σ_s W(s)[cos(ωs) − i sin(ωs)]`.
`W` 짝 ⟹ `W(s)sin(ωs)` 홀함수 ⟹ 허수부 합 = 0 ⟹ `Ŵ` 실수.
`W` 홀 ⟹ `W(s)cos(ωs)` 홀함수 ⟹ 실수부 합 = 0 ⟹ `Ŵ` 순허수.
역은 짝/홀 분해와 선형성. ∎

**따름 — 무엇을 저장하는가**

```
β = 0     +cos Δφ   대칭 창, 헤비안       w 가 (t,n) 대칭  →  에너지 함수  →  상태 저장
β = π     −cos Δφ   대칭 창, 반헤비안     동                 (어트랙터)
β = ±π/2  ∓sin Δφ   반대칭 창, 인과       w 가 반대칭      →  회전         →  순서 저장
                                                              (계열)
```

대칭 행렬은 고유값이 실수 → 이완·고정점. 반대칭은 순허수 → 회전·노름 보존.
**대칭 창은 홉필드형 오토연상 기억을, 비대칭 창은 계열 사슬을 만든다.**

## §7. 표준 창의 명시적 변환 (검산)

```
W(s) = A₊ e^{-s/τ₊} Θ(s)  −  A₋ e^{+s/τ₋} Θ(−s)

Ŵ(ω) =  A₊τ₊ / (1 + iωτ₊)   −   A₋τ₋ / (1 − iωτ₋)
```

극한 둘:

```
ω → 0 :   Ŵ(0) = A₊τ₊ − A₋τ₋  ∈ ℝ     DC 는 순수 짝수(동시성)
                                        균형 조건 A₊τ₊ = A₋τ₋ ⟺ Ŵ(0) = 0
                                        = 정상 활동에 안 쌓임 = 자기정규화
ω → ∞ :   Ŵ(ω) ≈ −i(A₊+A₋)/ω  ∈ iℝ    고주파는 순수 홀수(인과)
```

⟹ 표준 창은 `ψ(ω)` 가 저주파 0 → 고주파 π/2 로 쓸려 올라가는 필터다.
"느린 성분에서는 동시성, 빠른 성분에서는 인과" 를 잰다.

자기정합 검산: `A₊=A₋=A, τ₊=τ₋=τ` (완전 균형 = 홀함수) 이면
`Ŵ = −2iAωτ²/(1+ω²τ²) ∈ iℝ` — 모든 `ω` 에서 순허수. §6과 일치. ✓

## §8. `ẑ` vs `Z` — 유일하게 자명하지 않은 대응

```
ẑ_{t,j}(k) = [W_C h_t(k)]_j / ‖W_C h_t(k)‖      ← h_t(k) 하나만 있으면 계산됨
Z_t(j;k)   = x_t(k) + γe^{-iω_j}x_t(k−1) + ⋯    ← 이력 전체가 있어야 계산됨
```

### (A) 이력 — ★ 진짜 구멍

좌변은 한 시점의 함수, 우변은 이력 전체의 함수.

그런데 `h_t(k)` 는 재귀 상태다. 선형이라 치고 풀면 `h(k) = Σ_m M^m b(k−m)` 이고,
고유방향 `v_j` (고유값 `λ_j = |λ_j|e^{iω_j}`) 로 사영하면

```
v_jᵀ h(k) = Σ_m |λ_j|^m · e^{i ω_j m} · (v_jᵀ b(k−m))
             └감쇠┘   └회전┘
```

**`Z` 와 같은 모양이다.** `γ = |λ_j|`, 주파수 `= ω_j`.

```
(H′)  ẑ = Z  ⟺  W_C 의 행이 블록 사상 야코비안의 좌고유벡터와 정렬
                 & 동역학이 선형에 가까움 & {arg λ_j} 가 퍼져 있음
```

**미검증.** 그리고 설계상 근거가 없다 — `θ_j` 는 **격자 위의 공간 파수**로 설계된 것이지
블록 축의 시간 주파수가 아니다.

### (B) 정규화 — 무해

```
Z  :  Σ_j |Z_j|² 자유 (총 활동량)
ẑ  :  Σ_j |ẑ_j|² = 1  (강제)
```

- 위상: 양수로 나누므로 편각 불변 → **정확히 대응**
- 성분 간 비율(스펙트럼 모양): 나누기가 비율을 안 바꿈 → **대응**
- 총 크기: 지워짐. 다만 그 자리가 STDP 에서 하는 일(활동량)은 **값 사영이 맡는다** (§10)
  → 주소 쪽에서 소거되는 건 손실이 아니다

### (C) 신호 정의 — 선택의 자리

우변은 "토큰 `t` 의 신호 `x_t(k)`" 를 요구한다. STDP 에선 스파이크 열이다.
우리 모델에서 그게 `h_t` 인지 그 사영인지는 정해진 게 없다. 고르는 방식이 (A)의 조건을 바꾼다.

## §9. 잔차 흔적 — (A)를 가정에서 정의로

`W_C h` 가 우연히 필터 뱅크이기를 바라는 대신, `z` 를 필터 뱅크로 만든다:

```
z_{t,j}(k) = μ_j · z_{t,j}(k−1) + √(1−ρ_j²) · [W_C h_t(k)]_j ,   μ_j = ρ_j e^{i ω_j}
           = Σ_m ρ_j^m e^{i ω_j m} · [W_C h_t(k−m)]_j             ← 정확히 Z_t(j;k)
```

- `ρ_j = sigmoid(·)` → `|μ|<1` 보장, 발산 불가. 노름은 `|u|_max/(1−ρ)` 로 유계
- `√(1−ρ²)` 는 백색 입력에서 정상상태 분산을 `j` 에 무관하게 맞춘다
  (없으면 느린 성분이 `1/(1−ρ)` 배로 커져 스펙트럼을 독식)
- `ω_j` 는 **시간 주파수**로, `θ_j`(공간 파수)와 **별개 파라미터**다.
  `j` 가 몰래 시간 축이기를 바랄 필요가 없다
- **읽기 커널은 순간 `û`, 쓰기 창은 흔적 `ẑ`.** 읽기에 흔적을 쓰면 결합이 느려져 전파가 죽는다
  (`λ=1` 실패와 같은 함정 — 이 아키텍처에서는 `a` 가 곧 계산이다)
- 정규화는 재귀 **밖**에서만 (`ẑ = z/‖z‖`). 안에 있으면 풀었을 때 변환 형태가 깨진다
- **현재 아키텍처는 `ρ_j ≡ 0` 인 특수해**다. 표현력이 줄지 않는다

**대가**: 상태가 토큰당 복소 `H×p` 만큼 늘고(`h` 와 같은 크기), 고정점에서
유효 주소가 `1/(1−μ_j)` 로 가중되어 **고정점 집합 자체가 달라진다.**

## §10. 두 사영은 STDP 의 두 인자다

```
STDP :   Δw  =  W(관계 변수)      ×   (활동 곱)
                └── 창 ──┘           └ 공분산 규칙이면 부호 있음 ┘

v1   :   G   =  a_β(주소 관계)     ×   agree(값 상관)
                └─ W_C 사영 ─┘        └─ W_sh 사영 ─┘
```

**주소/값 분리는 결함이 아니라 가소성 규칙의 두 인자다.**
주소가 창의 인자(관계 변수)를 주고, 값이 활동을 준다.

그리고 `G ≠ Γ` 를 만드는 두 경로는 **동등하지 않다**:

```
β      같은 주소 공간 안의 위상 회전     같은 정보를 다른 각도로 읽음
agree  다른 사영을 끌어옴                읽기 커널이 못 보는 정보를 더함
```

`β` 만으로 만든 `G` 는 `a` 의 회전된 판본이라 `w` 가 적분해봐야 **읽기가 이미 아는 것의 흐릿한 사본**이다.
`agree` 는 값 공간을 물고 들어오니 새 정보다. **`β` 는 `agree` 가 하는 일을 구조적으로 못 한다.**

## §12. 미해결

1. **크기 스펙트럼 `c_j` 없음.** `Ŵ_j = e^{-iβ_j}` 로 `|Ŵ_j| ≡ 1`.
   `D(Δ)` 는 헤드별이라 `Σ_j` 바깥이므로 대신하지 못한다.
   `G = Σ_j c_j r r cos(Δφ′_j + β_j)` 로 두면 `Ŵ_j = c_j e^{-iβ_j}` 가 완전해진다 (헤드당 `p` 개).
   (참고: 원본 코어의 `α` 는 성분별이었고 `alpha_per_head=True` 가 헤드별로 묶었다.
    성분별 `α_j` 였다면 `D_j(Δ)` 가 합 안에 들어와 이 자리에 부분적으로 맞았다.)
2. **읽기의 `λ` 가 유도되지 않는다.** 정석 읽기 `w·v` 는 이 아키텍처에 안 맞는다 —
   `a` 가 곧 계산이라 전달에서 뺄 수 없다. 그래서 `(1−λ)a + λw` 덧셈이 강제되지만 `λ` 값은 미유도.
3. **`a` 와 `w` 가 왜 둘 다 필요한가.** "병렬 시냅스의 합" 은 이름이지 유도가 아니다.
4. **`w` 가 고정점에서 독립 자유도가 아니다** (`w* = g·G(h*)`). 기여가 전부 과도상태에만 있다.
5. **경계(쌍선형)와 `Φ` 가 이론 밖.** 블록의 절반이고 실측상 결정적인데(선형 경계는 셀 0.64 벽·완답 0)
   유도가 전혀 안 닿는다.
6. **`agree` 의 형태.** 공분산 규칙은 평균을 뺀다 (`(x−x̄)(y−ȳ)`). 우리는 안 뺀다.
   중심화 없는 헤브는 폭주가 정설이고, `churn` 의 원인일 수 있다.
7. **(H′) 미검증.** 야코비안 고유값 편각의 분산과 `W_C` 정렬을 재면 갈린다.

## §13. 정정 기록

이 유도에 이르는 동안 내가 틀렸던 것들. 결론이 바뀐 것만.

1. **"전체를 한 번에 푸리에 변환"** (프레임 A) — 층위 오류. `∫W(s)C(s)ds` 의 `C` 가 이미 시간
   적분을 포함하므로 완성된 `Δw` 다. 우리 `a_β(k)` 는 블록 증분이라 누적을 두 번 세게 된다. **폐기.**
2. **"`Re` 가 위반 지점"** — `Re` 는 결과지 원인이 아니다. 순수 위상에서 실수를 뽑는 유일한 방법이다.
3. **"정규화(1일차)가 위반 지점"** — 틀렸다. 정규화가 죽인 건 `r_t·r_n` 곱뿐이고,
   그건 쌍에 대해 인수분해되므로 관계를 담을 수 없어 애초에 쓸모없다.
   관계를 담는 실수 지수는 위치 스케줄(`U` 마스크)일 수밖에 없고, 그건 정규화와 공존했다.
4. **"멀다를 표현 불가"** — 무한 정의역의 논리를 유한 격자에 적용한 오류.
   `cos` 은 `[0,π]` 에서 단조 감소하고, 성분 52개면 푸리에 급수라 임의 함수를 합성한다.
5. **"활동변수가 없고 필요도 없다"** — 틀렸다. 나는 활동을 **진폭**에서 찾았고
   (`ẑ` 정규화와 `Φ` 가 두 번 지우므로) 없다고 판단했다. 활동은 진폭이 아니라
   **다른 사영(값 공간)** 에 있었다. §10.
6. **"`agree` 가 부호를 가져 STDP 위반"** — 틀렸다. `ν ≥ 0` 은 순수 헤브 얘기고,
   실제로 쓰이는 **공분산 규칙은 부호가 있다** (`(x−x̄)(y−ȳ)`).
7. **"`agree` 를 제거해야 한다"** — 위 5·6에 근거했으므로 함께 철회. `agree` 는
   가소성이 값 공간을 보게 하는 유일한 통로다.
8. **"`τ_w > 학습 지평` 이 외삽의 필요조건"** — 반례가 기록 안에 있었다.
   182k 는 `τ_w` 3.1~5.0 세그(지평 16세그의 1/3)로 36.2% 를 냈다. 충분조건이지 필요조건이 아니다.
9. **"게이지 상수화가 외삽 실패의 원인"** — 182k 가 같은 상수 게이지로 36.2%.
   그리고 v1 의 `es=7.6` 은 학습된 최적값이 아니라 **초기화 산물**이다
   (310k 동안 `‖E‖÷23 · β×30`, 곱은 `×1.3` — 평평한 게이지 방향을 미끄러졌을 뿐).
10. **"감소율 대신 절대 성능을 봐야 한다"** — 틀렸다. 절대 성능으로도 v1 이 1등이고
    (seg128 57.0% vs v1.6 49.2%), 무엇보다 **같은 가중치로 반복만 더 줘서 50%→77% 가 되는 것 자체가
    연구 대상**이다. 지평을 늘리면 재려는 현상이 사라진다.
