## 0. 결론 먼저

1. **스도쿠 돌파판(R1B8)은 "계산이 라우팅(장)에 있다"는 CA 명제 25 의 반대편에 있다.**
   CA 는 어텐션 그래프의 86% 가 입력별로 다르고(장 = 계산), R1B8 은 **70% 가 입력 무관 정적 피어 그래프**이며
   후기 블록 간 재배선 Δa/‖a‖ 는 0.09 뿐이다. 계산은 **경계 SwiGLU(토큰 내 채널 비선형)** 로 옮겨갔다:
   경계 놕아웃 0.70→0.23, 어텐션 놕아웃 0.70→0.39, **선형 대체(릿지 R²=0.97)도 0.35 로 붕괴** — 분산의 3% 에 계산이 산다.
2. **깊이는 쓰이지 않는다.** B16 은 블록 1개 제거 Δ=−0.0001, 4블록 절단 = 16블록 동률; R1B8 은 세그당 1블록만 실행해도 0.679(전체 0.684).
   세그 곡선도 3세그에서 포화. ⟹ 4일차 "SwiGLU = 깊이 지불" 가설은 **추론 시 함수 수준에서 기각** — 학습된 해는 세그당 1~2회 적용의 고정점.
   B24/B32 사다리는 이 해석 위에선 기대값이 없다.
3. **비대칭의 정체 = 알파벳·연산 종류.** CA(2상태)는 부호 하나가 상태라 방향 정규화+부호 어텐션이 문턱을 공짜로 주고, 라우팅 재배선이 곧 논리다.
   스도쿠(9상태)는 토큰 내 후보 벡터의 **첨예화(커밋)** 가 필요하고, 명제 21(장 고정 시 채널별 선형)의 코어는 이를 못 한다.
   실측: SwiGLU 는 매 블록 로짓 엔트로피를 0.26→0.20 으로 줄이고(첨예화), 어텐션은 0.20→0.26 으로 되돌린다(전파). 역할 분업이 정확히 [MLP=커밋, 어텐션=전파].
4. **고충의 정직한 형태**: "활성화 없음" 은 코어(MNIST/CA)에서만 참. 스도쿠에선 SwiGLU 가 상태를 h 의 136% 만큼 움직이는 **주 연산자**이고
   어텐션 스텝(82%)이 부연산자다. 논문 축은 "해석 왕관(조건부 선형)의 대가 = 토큰 내 논리 불능" 으로 잡는 것이 맞다.

## 4. 고충 정리 (현재 상태)

1. **주장 정합**: "활성화 없음" 은 코어 한정. 스도쿠 판은 SwiGLU 가 주 연산자(변위 136% > 어텐션 82%). 논문에서 코어/스도쿠 판을 분리 기재.
2. **깊이 축 폐기**: B24 재발사·B32 사다리·K-커널·μ 프로브는 추론 함수가 깊이를 안 쓰므로 우선순위 최하. 4일차 미시도 셀 중 **LSH832 도 불필요** (선형 경계는 표현상 불능).
3. **미해결 칸 순환 = 탐색 종료 기제 부재**: exact 천장(~0.71, URM 도 동일)은 "모순 검출·되돌림" 부재. 이건 SwiGLU 로도 안 풀림 (URM 도 벽).
4. **해석 왕관과의 충돌 확정**: 명제 21 은 코어에서만 성립; R1B8 은 SwiGLU 게이트를 장에 추가해야 조건부 선형이 복원 — 그러면 "장" 이 토큰별 게이트 2304×81 개를 포함해 해석 가치가 희석.
5. 데이터: 3일차 1k 서브샘플 ≠ 4일차 시드 0 서브샘플. 테스트 2048 은 동일(재현 확인).

## 5. 제안 (미실행, 학습 필요)

- **코어 안에서 토큰 내 첨예화를 주는 최소 부품** 탐색 — 활성화 없이: (a) `b` 채널 통로 확장 `(Σd)·b → diag(d^(m))·B`(헤드별 벡터, 여전히 장-조건부 선형), (b) 토큰 내 자기 어텐션(채널을 토큰으로 보는 2차 게이팅 — 원소곱의 이차형식 근사), (c) 진폭 채널 ‖h‖ 의 헤드별 분리.
  판정 기준: 아핀 대체 프로브(§2.3)를 그대로 써서 "코어만으로 R1B8 의 비선형 잔차를 얼마나 재현하나".
- **N2 직접 검증** (싼 CA 실험): `ca_task.py` 에 q-상태 알파벳(예: 3색·9색 Potts CA) 추가 → 순수 코어가 q≤H 에서 되고 q>H 에서 죽는지. 4×4 스도쿠(알파벳 4<H) 순수판도 동치.
- **N3**: CA Rule110 k=8 을 8스텝 detach + clip 없음으로 재학습 — 체제가 벽을 만드는지.
- 탐색 종료 기제: 순환하는 미해결 칸에 대한 "모순 에너지" 항 — 이건 아키텍처 확장이며 URM 도 못 하는 것이라 차별화 축 후보.

## 6. 추가 (같은 날 후속) — 게이트 함수 교체: 벽의 변수는 활성화가 아니라 **채널곱** (`code/gate_swap.py`)

R1B8 체크포인트에서 **재학습 없이** 경계 `W_d[act(W_g h) ⊙ W_u h]` 의 `act` 만 바꿔 512퍼즐 추론:

| act | 셀 | 완답/512 | 비고 |
|---|---|---|---|
| silu (원판) | 0.6995 | 27 | |
| **x/2 — 쌍선형 g⊙u/2, 활성화 0개** | **0.6730** | 13 | 원판의 96% |
| **x/2 + x²/4 — 다항 게이트, 활성화 0개** | **0.6984** | 25 | 사실상 동일 |
| x/2 + x²/4 − x⁴/48 | 0.6993 | 27 | silu 테일러 4차 = 원판 |
| gelu | 0.6907 | 21 | |
| relu (하드 게이트) | 0.4478 | 10 | silu 의 **곡률**이 중요, 스위칭은 아님 |
| x (항등 게이트, g⊙u 그대로) | 0.2079 | 0 | 스케일 2배 — 곱 자체는 있으나 학습 스케일 이탈 |
| 상수 0.5 (= 선형 경계 `h + W'h`) | 0.2055 | 0 | 4일차 선형 3형식의 추론판 |

판정:
- 4일차 절제에서 빠진 셀은 **`g ⊙ u` (silu 제거, 곱 유지)** 였다. 4일차 `R1B8_LIN` 은 `down(g+u)` 로 곱까지 없앤 함정판.
- silu 를 2차 다항식으로 바꿔도 성능이 유지되므로 **"활성화 함수 없음" 주장은 스도쿠에서도 복원 가능** — 경계를 토큰 내 2차(쌍선형) 사상으로 두면 된다.
  이는 사양의 원래 철학(다항식·C^ω 동역학, 채널 축 차수 성장 2^B)과 정합하고, 조건부 선형성(장 = {a, d, ‖h‖} + 토큰별 게이트 벡터 g)도 그대로 성립한다.
- 추론 치환이 이 정도면 학습 치환(쌍선형 경계로 처음부터 학습)은 더 잘 맞을 가능성이 높다. **제안 1순위: `boundary = h + W_d[(W_g h)⊙(W_u h)]` 로 R1B8 재학습** (플래그 1개, 파라미터 동일).

### 7.7 튜링 패턴·CA 클래스·ARC (논의 정리)
- 블록 = [반응(칸별 다항식 + 강제항) → 확산(부호 커널 위 종별 수송) → Φ 포화]. 종 = `W_mᵀW_m` 고유기저, 확산율 = 고유값(명제 26); 커널 = 감쇠×코사인 = 멕시칸 햇(명제 22); Φ = Swift–Hohenberg 의 −u³ 자리(포화 반경 실측 §7.5).
  초기 해는 고정 그래프(교과서형 RD), 후기 해는 상태 의존 확산(준선형) — §7.4.
- 계산 = 균일 초기상태 + 핀(주어진 칸) 하의 **패턴 선택**. 탐색 실패 = 다중안정성(§7.6). 답 = 능동 유지되는 비평형 정상상태(3일차 주입/소산 비 1.9).
- ARC: HRM/URM 프로토콜(과제 id 임베딩)에서는 "고정 프로그램·변하는 입력" = CA 클래스. 요구 = **클래스 4 기계 위의 클래스 2 궤적 선택**. 우리 측정량으로 판정 가능: λ(FTLE, 스도쿠 판 미측정), 과도 꼬리(커밋 90%ile 102), 진동형 띠(이동 구조 지지), 고정점.
  불일치: 격자 크기 변화 과제, 비국소 카운팅, 과제 400+를 가산 벡터로 구분.
- 제안(완주 후): ① 이산 분산관계 |μ(k)| (빈 판 균일상태, `dispersion.py` 재사용) ② 다중안정성 측정(init 잡음 N회 → 서로 다른 자기일관 격자 수) ③ **Wolfram 클래스별 CA 학습 가능성 표**(Rule 4·184 / 110 / 90 / 30·45) + 다중 규칙 id 임베딩 = ARC 전 단계.
