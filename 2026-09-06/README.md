## 6. 이론 (해석)

### 6.1 과도상태 완성

```
빠름:  h_{k+1} = F(h_k; w_k)                       세그먼트 사상
느림:  w_{k+1} = (1−δ')w_k + δ'·G(h_k)              δ' ≈ 8δ
```
δ'≪1 이면 h 는 현재 w 의 고정점 h*(w) 로 떨어지고 긴 지평의 동역학은 `ẇ = δ'(G(h*(w)) − w)` 하나다. 학습은 k≤16 의 h*(w_k) 만 본다. 느린 헤드(δ' ≈ 0.024, 1/δ' ≈ 40세그)에서 seg16 은 궤적의 33% 지점 — 학습이 앞 1/3 의 **방향**을 새겼고 추론이 나머지를 간다. 10k(1/δ' ≈ 3세그)는 seg3 에 끝난다. **이득 = 학습 지평에서 w 가 자기 고정점으로부터 떨어진 거리**, 상한 있음(과도상태는 끝난다: seg192 이후 포화). §3.1 의 δ 스윕이 이 예측의 검정이다.

### 6.2 왜 학습이 9/1 에서는 δ 를 내리고 v2.1 에서는 안 내렸나

느린 w 가 유용하려면 w 가 순간 계산으로 못 얻는 것을 담아야 한다. 9/1 의 목표 `a_β·agree` 는 읽기 커널과 다른 함수(정렬 검출기)라 그 이력이 정보다 → δ↓. v2.1 의 목표 `â` 는 읽기 커널 자체라 느려봤자 저역통과, 빠르게 복사하면 exp 와 합쳐 날카로움 이득 → δ↑. **G≠Γ 는 문헌 부합이 아니라 경사가 느린 적분을 고르게 하는 조건.**

### 6.3 unlearning 으로서의 w

`w ∝ ⟨a_β·agree⟩` 가 a 와 반대 부호로 쌓여 일관된 쌍의 결합을 서서히 약화한다 (§5). 구조상 Hopfield–Crick–Mitchison 의 반헤비안 항인데 (i) 가중치가 아니라 에피소드 변수라 정답 끌개는 안 깎이고 (ii) 양의 국면은 SGD 가 학습 시점에 맡아 공적응돼 있고 (iii) 정답은 고정점이라 침식이 무력하고 가짜 해는 고정점이 아니라 잔차가 이긴다 → 해결16→미해결 0%. **탈출 기제가 없다고 했던 것이 여기 있었다.** 다만 "반헤비안 부호"보다 "정렬 검출 커널"이 1차라는 것이 §3 의 판정.

### 6.4 이것은 추론 중 학습이 아니다

패턴 굳힘도 끌개 선택도 아니고, 학습 때 방향이 정해진 궤적의 재생이다. 쿠라모토·STDP 어휘가 가리키던 현상과 다르다. 무한정 외삽하려면 새 드리프트를 계속 만드는 기제가 따로 있어야 한다.

## 9. 오늘의 실패 기록

**무엇을 시도했나.** 9/1 의 외삽이득 원인을 "쓰기 커널이 읽기 커널과 다르다(a_β ≠ a)" 로 보고, β≈0 이 확인되자 "G ⊥ Γ 가 필요하다" 로 옮겨 ③(perp 쓰기 `G=a(ψ+π/2)` + prod 읽기 `a_eff = w·a`)을 설계, 캐글(플래그판)과 로컬(v3, |Z| 정규화)에서 돌렸다.

**결과.** 캐글 ③ 176.6k: 감소율 7.8~10.4% (9/1 재현 120k 32.9%), 느린 헤드 gain→0, δ 극단 양봉. v3 60k: 정확 127/512, 감소율 13.8%, 정체 + gain 하락. 둘 다 9/1 재현에 못 미침.

**틀린 곳.** 쓰기가 아니라 읽기다. 쿠라모토 적응 결합 `φ̇ = ω + ΣKΓ` 에서 `K·Γ` 항만 옮기고, 그 식이 전제하는 **K 와 무관하게 상태를 움직이는 항**(문헌에서는 ω 또는 κ(0)=O(1) 무작위 초기 결합)을 안 옮겼다. 곱 읽기는 유일한 전달 채널(a)을 w 로 게이트하므로 (i) w≈0 인 초기·에피소드 첫 블록에 전달이 없고, (ii) Δφ 가 안 움직여 G 가 한 점만 표본화되어 w 가 복사본으로 퇴화하고, (iii) "seg16 안에 풀기"(τ 작게)와 "seg16 넘어 움직이기"(τ 크게)를 같은 τ 가 떠안아 δ 가 양봉으로 찢어진다. 정상상태에서 `w·a ∝ sin 2χ` 라 주소의 대척점을 구별 못 하는 것도 증명됨(ẑ_t→−ẑ_t 불변).

**하루 동안 잘못 짚은 것들.** "a_β ≈ −a"(R(ψ)=0.22 로 기각) → "β≈0 은 G=Γ 퇴화, ⊥ 필요" → "덧셈은 곱의 근사" → "a 는 장기 시냅스"(유비, 철회) → "덧셈은 지연 결합"(레퍼런스 교체, 철회). 최종: **a = 순간 시냅스 K_fast = G(Δφ(t)) (K̇=ε(G−K), ε→∞), w = 같은 G 의 느린 적분 K_slow (ε=δ), 읽기 = (K_fast+K_slow)·Γ — 병렬 시냅스의 합.** "ω 자리" 는 이것을 돌려 말한 것. 9/1 의 이득 요소는 "w 와 무관한 전달 채널 + 느린 w 채널의 중첩"이고, ψ+90° 쓰기의 기여는 미지(덧셈과 조합해 본 적 없음). §4.1 의 "G=Γ 퇴화" 주장은 덧셈 아래서는 약화됨(w = a 의 시간 평균 = 관성 필터).

**교락.** 쓰기(perp)와 읽기(prod)를 동시에 바꿔서 어느 쪽이 원인인지 실험으로 못 갈랐다. 위 판정은 이론이다.
