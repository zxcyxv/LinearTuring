## 2. STDP 와의 대응 — 주파수 영역

바깥(절대 시간 누적)은 그대로 두고 **안쪽(창의 합성곱)만** 변환한다.

```
STDP  w(T) = ∫dk · S_t(k) · [ Σ_u W(u) S_n(k−u) ]      바깥 = 누적,  안쪽 = 흔적
우리  w(k) = δ Σ_m (1−δ)^m · G(k−m),  G = Σ_j r r cos(Δφ_j + β_j)
```

바깥끼리는 정의상 같다. 안쪽을 전개하면 (pre 쪽 켤레):

```
Σ_j Z_n(j;k)* Ŵ_j Z_t(j;k) = Σ_{m,m′} γ^{m+m′} S_n(pre시각) S_t(post시각) W(post−pre)
```

**성분합 `Σ_j` 가 시간 이중합 `Σ_{m,m′}` 을 복원한다** (항등). 대응 사전:

| STDP (주파수) | 우리 | 상태 |
|---|---|---|
| 주파수 ω | 성분 j | (H′) 필요 |
| `\|Ŝ_pre\|\|Ŝ_post\|` | `r_{n,j} r_{t,j}` | 정규화로 총 크기 소거 — 대응 상대 없으므로 무해 |
| `Δθ(ω)` | `Δφ_j` | 대응 |
| `ψ(ω) = −arg Ŵ(ω)` | `β_j` | **항등** — 창의 위상 스펙트럼 |
| `\|Ŵ(ω)\|` | 없음 (≡1) | **빈칸: 크기 스펙트럼 `c_j`** |

**정리**: `W` 짝함수 ⟺ `Ŵ` 실수 ⟺ `β ∈ {0,π}` (대칭 창, 상태 저장)
       `W` 홀함수 ⟺ `Ŵ` 순허수 ⟺ `β = ±π/2` (반대칭 창, 순서 저장)

v1 실측: `sin²β = 0.10` (거의 순수 대칭 창), `sin²ψ = 0.32` (실수 우세, 부호 혼합, 무작위 0.5 아래).
⟹ 학습이 **어트랙터(상태 저장)** 쪽을 골랐고, 이 과제 구조와 맞는다.

**유일한 구멍**: `ẑ_{t,j}(k)` 는 `h_t(k)` 한 시점의 함수인데 `Z_t(j;k)` 는 이력의 가중합이다.
선형 재귀의 고유방향 사영이 정확히 `Σ_m |λ|^m e^{iωm}(...)` 이므로 원리적으로는 가능하나
`W_C` 가 야코비안 고유벡터와 정렬한다는 보장이 없다 → **v1.6 이 잔차 흔적으로 이 구멍을 닫는다.**

부수 정정: `agree ∈ [−1,1]` 은 활동 인자 자리인데 이 계엔 활동변수가 없고(진폭 두 번 정규화)
부호까지 가져와 창의 역할을 침범한다 → 제거.

**v1 → v1.5 (규약)**

| | v1 | v1.5/v1.6 |
|---|---|---|
| 블록 순서 | `pre`: 경계 → 주입 → (어텐션+수송+Φ) | **`post`**: 주입 → 스텝 → 경계 → Φ |

| 임베딩 초기화 | 파이토치 기본 N(0,1) | `trunc_normal(std=1/√d)` |

**v1.5 → v1.6 (이론)**

```
쓰기 목표    G = a_β · agree   →   G = a_β                       agree 제거
주소         û = W_C h(k)/‖·‖  →   û (읽기) + ẑ (쓰기, 흔적)      잔차 흔적 도입

z_{t,j}(k) = μ_j · z_{t,j}(k−1) + √(1−ρ_j²) · u_{t,j}(k),   μ_j = ρ_j e^{i ω_j}
           = Σ_m ρ_j^m e^{i ω_j m} u_{t,j}(k−m)              단시간 변환 계수
```

- `ρ_j = sigmoid(·)` → `|μ|<1` 보장, 발산 불가. `√(1−ρ²)` 는 정상상태 분산을 `j` 에 무관하게 맞춤.
- `ω_j` 는 **시간 주파수**로, `θ_j`(격자 공간 파수)와 **별개 파라미터**다.
- **읽기 커널은 순간 `û`, 쓰기 창은 흔적 `ẑ`.** 읽기에 흔적을 쓰면 결합이 느려져 전파가 죽는다(λ=1 실패와 같은 함정).
- 정규화는 재귀 **밖**에서만 (`ẑ = z/‖z‖`). 안에 있으면 풀었을 때 변환 형태가 깨진다.
- 유지: 거리 감쇠 `D(Δ)`, 단일 gain, 덧셈 읽기 `(1−λ)a + λw`.
- **의도적 미구현**: 창의 크기 스펙트럼 `c_j`. 현재 `Ŵ_j = e^{−iβ_j}` 로 `|Ŵ_j| ≡ 1`.
  → 다음 절제: `D` 제거 + `c_j` 도입.
