# 2026-09-01 — 추론 시점 세그먼트 외삽

학습은 16 세그먼트(`loops=16`, `blocks_per_seg=8`)로 했다. 가중치를 건드리지 않고 추론에서 세그먼트만 더 준다.

## 스크립트

`analysis/seg_extrap.py` — 학습 하네스(`refs/URM/pretrain.py` + `models/losses.py`)와 같은 정의로 채점한다.
`accuracy` = 81칸 중 맞은 비율, `exact` = 81칸 전부 맞은 퍼즐 수, `churn` = 직전 세그먼트 대비 답이 바뀐 칸 비율.
가중치는 `model_state_dict`(= EMA 적용본, `ema_shadow` 와 비트 동일함을 확인)를 쓰고, 버퍼(`init_hidden`, `puzzle_emb.weights`)는 `raw_model_state_dict` 에서 가져온다.

**seg 16 에서 학습 로그와 일치함을 확인했다** (B: acc 0.8301 / 완답 1043 vs 로그 step 310527 의 exact 1043/2048). 하네스 재현이 맞다는 뜻이다.

```bash
python 2026-09-01/analysis/seg_extrap.py --segs 256 --bs 256                      # B
python 2026-09-01/analysis/seg_extrap.py --ckpt checkpoints/R1B8_min_stdp1_step228501.pt \
       --config checkpoints/R1B8_min_stdp1_config.yaml --segs 256 --bs 256 --tag stdp1
python 2026-09-01/analysis/seg_extrap.py --segs 256 --bs 256 --lam 0 --tag faith_lam0   # 절제: 결합 기억 끔
```

두 모델은 같은 `minimal` 구조다. 다른 것은 결합 기억의 형태와 설정뿐이다.

| | stdp1 | B |
|---|---|---|
| Γ | `a·⟨v̂,v̂⟩` | `a^β·⟨v̂,v̂⟩` (가소성 창 × 동시활동) |
| λ | 1.0 고정 | 학습, 평균 0.305 (헤드별 0.185~0.478) |
| δ | 0.4906 (τ≈2블록) | 0.0903 (τ≈11블록) |
| G | 없음 (=1) | 0.712 (weight-decay 제외 목록 누락으로 학습 안 됨) |

## 절제: λ=0 (결합 기억 끔) — 정보 없음

`--lam 0` 은 완답 **0.00%**, churn 0.665~0.669 로 평평하다. 모델은 λ≈0.3 에서 학습됐으므로 λ=0 은 분포 밖이고
그냥 부서진다. "기억 없이는 작동하지 못한다" 는 말할 수 있으나, 수렴에 기억이 무엇을 기여했는지는 가리지 못한다.
가르려면 λ 를 그대로 두고 **세그먼트 경계마다 w 를 다시 계산하는**(누적 축만 절단) 대조가 필요하다
— `2026-08-30/analysis/extrap.py` 의 `stdp_reset` 변형과 같은 조작.
