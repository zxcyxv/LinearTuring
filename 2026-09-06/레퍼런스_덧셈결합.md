# 덧셈 결합(기저 전달 + 느린 가소성 항)의 레퍼런스 조사 — 2026-09-06 저녁

질문: 읽기 `a_eff = (1−λ)a + λw` (9/1) 를 원리로 합리화할 레퍼런스가 있는가, 더 나은 형태를 제시하는 레퍼런스가 있는가.
결론 요약은 맨 아래. 각 항목은 (식 → 우리 식과의 대응 → 덧셈/곱셈에 대해 말하는 것) 순서.

## A. 덧셈 형태를 문자 그대로 쓰는 문헌

### A1. Miconi, Stanley, Clune 2018 — Differentiable plasticity (ICML). arXiv:1804.02464
```
x_j(t) = σ( Σ_i [ w_ij + α_ij · Hebb_ij(t) ] x_i(t−1) )          (Eq.1)
Hebb_ij(t+1) = (1−η) Hebb_ij(t) + η x_i(t−1) x_j(t)              (Eq.2)
```
- w: 고정(SGD). α: 연결별 가소성 계수(SGD). η: 가소성 학습률 겸 감쇠(SGD). Hebb: 에피소드 시작에 0.
- 대응: `w_ij ↔ a` (SGD 가중치가 만드는 전달), `α ↔ λ`, `Hebb ↔ w`, `η ↔ δ`. 우리 9/1 읽기와 항별로 같다.
- 저자 설명: "총 가중치 = 기저(고정) 가중치 + 가소성 계수 × Hebb 흔적". α=0 이면 완전 고정 연결. 즉 **고정 항이 있어야 Hebb 가 쌓이기 전에도 망이 동작한다**는 설계.
- Backpropamine (Miconi 2019, arXiv:2002.10585) 은 같은 식에 신경조절 인자 M(t) 를 η 자리에 둔 것.

### A2. Ba, Hinton, Mnih, Leibo, Ionescu 2016 — Using Fast Weights to Attend to the Recent Past (NeurIPS). arXiv:1610.06258
```
A(t) = λ A(t−1) + η h(t) h(t)ᵀ                                    (Eq.1)  쓰기
h_{s+1}(t+1) = f( [W h(t) + C x(t)] + A(t) h_s(t+1) )             (Eq.2)  읽기, 내부 반복 s=1..S
```
- `[W h + C x]` 느린 가중치 항은 내부 반복 동안 **고정된 경계조건**으로 유지되고, 빠른 가중치 항 `A h_s` 가 거기에 **더해진다**.
- 대응: 내부 반복 s ↔ 우리 블록 반복. `[Wh+Cx] ↔ a·v 전달`(w 무관 항), `A ↔ w`, `λ ↔ 1−δ`.
- 동기: "작업기억·주의·프라이밍은 100ms~분 단위 — 활동으로는 너무 느리고 장기 가소성으로는 너무 빠르다" (Hinton & Plaut 1987 인용).

### A3. Hinton & Plaut 1987 — Using Fast Weights to Deblur Old Memories (CogSci)
- 연결마다 느린 가중치(장기, 가소적) + 빠른 가중치(단기, 탄성적, 0 으로 자발 감쇠). 유효 가중치는 합.
- 덧셈 두-시정수 가중치의 원조.

### A4. Bicknell & Latham 2024/25 — Fast and slow synaptic plasticity enables concurrent control and learning (eLife RP 105043; bioRxiv 2024.09.06.611710)
```
w_total = w_slow + δw_fast                                        (Eq.3)
```
- 빠른 항: ms~s, "하류 오차를 탐욕적으로 즉시 억제". 느린 항: 수백~수천 s, "통계적으로 최적인 학습".
- **이 분해가 LQG 최적제어 문제의 해로 유도된다.** 시간상관을 이용하려면 두 시정수가 필요하고, 각 시냅스가 국소적으로 둘을 동시에 구현한다.
- 조사한 것 중 덧셈 두-시정수 결합을 *원리에서 유도*한 유일한 문헌. 단, 여기서 빠른/느린 배정은 우리와 반대(빠른 쪽이 가소성). 유도의 골자 — "즉시 항 + 축적 항의 합" — 는 그대로 쓰인다.

## B. 곱셈이되 기저 1 인 문헌 (효능 변조)

### B1. Ellwood 2024 — Short-term Hebbian learning can implement transformer-like attention (PLOS CB; PMC10849393)
- 기저 AMPA 전도도에 시그모이드 인자를 **곱해** 조건 충족 시 8배. 기저 연결은 항상 유지.
- 형태: `a · (1 + w)` 계열. 기저 없이 곱하지 않는다.

### B2. Tsodyks–Markram 계열: Mongillo, Barak, Tsodyks 2008 (Science 319:1543) · 연관 전시냅스 STP (arXiv:2601.10397)
```
w_ij(t) = w⁰_ij · u_ij(t) · x_ij(t)        u,x ∈ (0,1], 기저 w⁰ 고정
```
- 단기 가소성은 고정 시냅스의 **효능을 변조**한다. w⁰ 가 0 이면 변조할 것이 없다.
- 2601.10397 의 논점: u 를 바꾸는 것과 w⁰ 를 바꾸는 것은 다른 동역학(u 는 즉시 전달과 이후 고갈을 동시에 바꿈). 즉 **곱셈 변조는 기저 위에서만 의미가 있다.**

## C. 순수 가소성(기저 0)이 동작하는 문헌 — 왜 동작하는지

### C1. 적응 결합 쿠라모토: Aoki–Aoyagi 2009 (PRL 102:034101), Berner–Yanchuk–Schöll 계열 (arXiv:2006.00890), Bronski et al. (arXiv:1611.09941), Ha et al. (J. Diff. Eq. 2025)
```
θ̇_i = ω_i + Σ_j κ_ij sin(θ_j − θ_i)          기저 결합 항 없음
κ̇_ij = −ε( κ_ij + sin(θ_i − θ_j + β) )       (또는 Hebbian  κ̇ = cos(Δθ) − ακ)
```
- κ 초기값: [−1,1] 균등 (Berner), [−0.015,0.015] (2006.00890), 1 또는 3 (Bronski 수치). **0 에서 시작하는 예는 없다.**
- Ha et al.: 비동일 진동수에서 위상 지름 D(t) ~ 1/(초기 최소 결합). 초기 결합이 작을수록 동기화가 나빠진다. Bronski: 고정점의 끌림 영역이 전체가 아니며 초기 결합이 작을 때 특히 좁다.
- 2512.20410 은 ω_i 를 대부분 0 으로 두고 κ(0)∈[−1,1]. 즉 이 문헌에서 "K 와 무관한 움직임"은 ω 가 아니라 **κ(0) 의 O(1) 무작위 초기값**이 공급한다.
- 함의: 순수 곱 `κ·Γ` 는 κ(0)=O(1) 을 전제한다. 우리 ③/v3 는 w(0)=a⊥(첫 블록), ρ≈0.08 → 사실상 0 근방 시작. 문헌이 한 번도 다루지 않은 초기조건.

### C2. Najarro & Risi 2020 — Meta-learning through Hebbian plasticity in random networks (NeurIPS). arXiv:2007.02686
```
Δw_ij = η (A o_i o_j + B o_i + C o_j + D)      고정 항 없음, w(0) ~ U[−0.1,0.1]
```
- 순수 Hebb 만으로 동작. 그러나 w(0) 가 비영 무작위이고, 30~80 회 갱신 안에 가중치 공간의 끌개로 수렴. D 항(활동 무관 상수 편향)이 있어 활동이 0 이어도 가중치가 움직인다.
- 함의: 기저 없는 가소성은 (i) 비영 초기값 또는 (ii) 활동 무관 구동항 중 하나가 있어야 자기부트스트랩한다. 우리 ③ 은 둘 다 없다.

가소성 항             α_ij Hebb_ij x_i     A h_s                    δw_fast               λ·w·v

## E. "더 나은 형태" 후보로 문헌이 주는 것

1. **기저 1 곱셈 `a·(1+w)`** — B1, B2 의 형태. 부호 보존(기저 항), 반전 가능(w<−1), w=0 에서 원래 커널. 적응 결합 문헌의 `K₀ + κ` 초기화와도 같은 꼴. 미시도.
2. **Bicknell–Latham 식 유도** — "즉시 오차 억제 항 + 통계 축적 항의 합"이 최적제어의 해라는 논리. 우리 외삽 서사("빠른 채널이 풀고, 느린 채널이 굳힌다")를 유도로 뒷받침할 수 있는 유일한 후보. 원문 §Model 의 Eq.3 유도 검토 필요.
3. Miconi 의 **Oja 변형** `Hebb ← Hebb + η x_j (x_i − x_j Hebb)` — 감쇠 없이 자기정규화. δ 없이 τ 를 쓰는 대안. 미검토.

## F. 결론

- 덧셈 `(1−λ)a + λw` 는 근거 없는 도입이 아니다. Hinton–Plaut 1987 → Ba et al. 2016 → Miconi et al. 2018 의 빠른-가중치/미분가능 가소성 계보가 **동일한 식**을 쓰고, Bicknell–Latham 이 그 합을 최적제어에서 유도한다.
- 쿠라모토 적응 결합의 순수 곱 `κ·Γ` 는 κ(0)=O(1) 무작위 초기값(그리고/또는 ω) 이 "K 와 무관한 움직임"을 공급한다는 전제 위에 있다. 우리 ③ 은 그 전제를 만족하지 않는다 (C1, C2).
- 곱셈을 살리려면 문헌은 기저 1 (`a(1+w)`) 을 쓴다 (B). 기저 0 곱셈을 쓰는 문헌은 없다.
- 오늘 오후 ③ 의 오류는 "적응 결합 식의 K·Γ 항만 옮기고, 그 식이 전제하는 비영 초기 결합/ω 를 안 옮긴 것"으로 문헌상 특정된다.
